# LIE 具体界面设计规范 v1

状态：用户已确认中文 B（黄蓝撞色 / 描边卡通）及交互原型，授权具体设计。此规范给 Vue / TypeScript 公共 UI 实现；模块架构已获用户确认。颜色与尺寸见 tokens.json；设计稿不增加玩法。

## 可立即实施的组件契约

- 原则：阳光黄底、暖白内容、钴蓝主操作、深蓝文字与 3px 描边；珊瑚 / 水蓝只作角色与装饰，不能表达撒谎或罪责。亲切的成人卡通，与推理题材形成轻松反差。
- Button：primary / secondary / quiet 三种；高度 56 / 最小 48px、圆角20px、字重600、水平24px。primary 蓝底白字，secondary 暖白底深蓝字，quiet 透明底无投影。hover 加深或轻微提亮；pressed 下移3px并减投影；disabled 灰底、文字灰、无投影；busy 保留标签和小状态图标、禁止重复激活。focus 外侧3px深蓝环、4px留隙；保留按钮本身边框。不能只有颜色区分。
- Card：暖白底、28px圆角、3px深蓝描边、24px内边距；可选卡 selected 用4px蓝边+“当前人物”标签，hover 不改变选中语义。组件用插槽承载头像、正文和操作，不内置人物ID、正确答案或供应商逻辑。
- StatusBadge：文字必需，图标辅助；idle“等待你开口”、recording“正在聆听”、waiting“等待回应”、speaking“正在说话”、error“语音暂时中断”。只有真实协议提供时才细分识别等阶段。状态不推断角色情绪。
- Avatar：人物统一粗轮廓、简洁色块、夸张但亲切的表情，普通 / 聆听 / 思考 / 说话动作仅用于语音反馈。缺图用姓名首字占位，不显示破图。首案三人，组件数量不写死。
- Dialog：暖白、32px圆角、最大960px、遮罩深蓝40%；标题+明确返回按钮，Tab焦点限制，关闭后恢复触发点；不能只靠点遮罩关闭。错误反馈为内联状态区。
- TranscriptItem：说话人+只读文字；玩家与角色可用左右 / 头像区别，不靠颜色；正文16px行高1.65。不提供文字输入。SystemNotice 独立语义，不伪装角色发言。
- VoiceControl：公共展示组件消费状态与操作可用性；发出 start / cancel / interrupt 意图，不自行录音、自动转状态或判断真伪。状态标签与按钮文字同步，实际业务决定操作。Waveform 接收输入幅度，无输入时静态，不用假波形假装收音。

## 屏幕与布局

桌面参考1440×900；主区最大1440px，左右32px，页面间隔24px。1024px视口收缩为横向人物条 + 主要对话区；内容不得固定高度裁掉操作。200%缩放允许自然纵向滚动。正文16px以上、说明14px以上；中文每行宜20–34字。系统中文字体，不额外下载未核实字体。

1. 接案：顶部LIE字标（暂用文本，最终字标另交）、居中暖白介绍卡；占位案件名、2–3行案情、目标一句话、三人小头像、流程“开口问话 → 对照说法 → 最终指认”；主按钮“接案，开始调查”。没有原型模拟控件，没有证据、评分、地图或关卡。
2. 审讯：顶部案件名+“最终指认”；左侧可滚动人物列表，中间当前人物半身，右侧只读转写；下方固定在内容流中的宽语音控制。人物名称、身份和当前标记常驻，长历史独立滚动；按用户后续要求，新对白插入或流式内容增长导致溢出时自动滚到底部，确保最新内容可见。转写始终展示，移除展开/收起控件，不隐藏主语音操作。
3. 指认：停止当前声音后打开居中弹层，标题“最终指认”，说明“谁取走了纪念章？”（占位），三张人物按钮“指认 林岚”等，直接选择即提交，沿用已确认原型；“返回调查”始终清楚可见。待响应禁重复提交；不能新增推理表单。
4. 错误反馈：留在指认弹层，暖白 / 水蓝内联通知，文字“指认错误。此人没有取走纪念章。你可以返回调查，重新听取三人的说法。”（占位）；主按钮“返回调查”，保留历史，不扣生命、不关局、不提前揭晓。
5. 正确结局：暖白主体卡，标题“指认正确”，人物小像、完整经过与简短解释；蓝色“重新开始一局”。可用静态珊瑚 / 水蓝几何装饰庆祝，无强制动画；重开回接案。真相文字由业务投影提供，不写进公共组件。

## 语音各状态

| 状态 | 主要反馈 | 操作 |
| --- | --- | --- |
| idle | 静态麦克风，“等待你开口” | 蓝色“开始说话” |
| recording | 麦克风+真实输入幅度，“正在聆听” | “结束说话”；如取消入口实际可用，再显示“取消本轮” |
| waiting | 小点或静态省略号，“等待回应” | “取消本轮”与允许时的“打断并说话” |
| speaking | 人物说话图标+“正在说话” | “打断说话”与“打断并说话” |
| error | 图标+简短原因，说明已发送与否 | “重试”或设备权限入口；无文字聊天兜底 |

切人、打开指认、离开本局时语音停止，已显示转写保留。取消 / 打断记录为系统提示，不作为角色证词。动画尊重 reduced-motion，避免闪烁；status播报只报阶段变化，不播每个波形值。

## 交付与验证边界

本轮位图设计稿使用已批准风格板做参考，人物、案名、对白与正确答案均为原型占位。位图用于视觉review，tokens与本规范是公共UI契约；图片中的文字错误或布局细节不自动改写契约。后续对照真实Vue界面检查中文换行、焦点、48px目标、缩放、减少动态效果与长文案。自动化优先覆盖组件事件、disabled/busy、dialog焦点和状态标签；视觉人员目检真实浏览器。真实音频测试不能由静态设计稿证明。
