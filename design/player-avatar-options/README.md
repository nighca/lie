三个SVG均为原创代码原生路径，64×64 viewBox，深蓝轮廓/钴蓝/珊瑚/黄水蓝，与已批准B品牌一致。没有引用第三方头像、字体或现成侦探IP，没有imagegen或位图编辑。人物不指定性别/年龄/故事身份。SVG自带title和aria引用，可独立编辑。头像背景与图形为完整矢量，不需要裁切素材；边缘留白已在viewBox内处理。

`build.py`重建索引HTML，`preview.css`只是静态比较板，转写泡泡为原生HTML/CSS示例，未连接运行时组件或语音服务，不代表新增功能。NPC例图直接引用现有coral-bob默认资源，未修改素材。
