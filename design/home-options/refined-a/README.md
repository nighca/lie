## 收敛点

桌面左右等宽：左侧用一句标题、必要产品说明与现有三人群像建立邀请感；右侧“选择案件”加统一纵向卡片提供入口。取消单案特殊排版，1、2或更多案件始终使用同一卡片与列表结构；本轮主稿实际展示两案。桌面列表随文档延展，左侧产品介绍 sticky 保持可见；窄屏改为介绍在上、案件在下，统一文档滚动，不嵌套列表滚动。

保留文案“有人，有话没说完。”“和角色语音对话，找出藏起真相的人。”；不加解释回看/如何点击等重复文案。卡片只保留序号、标题、公开简介、询问时长和“查看案件”入口。第一案8分钟；第二案《压轴怎么是鸭叫》题材与10分钟已批准，正式内容仍制作中，因此本静态稿标明“内容制作中 · 尚未上线”，没有可进入按钮。正式JSON与上线状态由内容/运行时负责人接入，本稿不模拟已发布。

## 布局契约

- 桌面最大宽1440，页面左右40，页眉64高；主区顶部34、两列 `minmax(0,1fr)`、列间56。在1280实测两列各572px。
- 标题52px/1.24，说明19px/1.7；人物群像高334，不新增或重绘角色。群像是产品插画，不作为所有案件的人物名单。
- 案件列表间22；卡片描边3、圆角26、实色下阴影5、padding 23px 28px 25px。标题27，简介15/1.8，主按钮最低48高。
- <=900缩小排版，<=620改为单列；391px实测卡片宽约355，无水平溢出。手机卡片padding20px 21px 22px，标题25，简介14；不为案件数量添加分支。
- 保持已批准首页→接案→调查和离开确认流程，按钮静态无行为；本稿不设计新分类、搜索、账号或玩法。
