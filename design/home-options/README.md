# 首页两版设计候选

基于 reviewed `f14f8c62aec83ae785344081faca14c86acddd7a`，独立分支 `codex/home-options`。只改本目录，不替换应用、案件catalog或流程。用户确认首页动线，但新版视觉仍待选择。

打开 [中文对比索引](index.html)，每版包含当前1案与未来2案、桌面与窄屏。本轮两版的区别是信息重心和布局，不只是配色/间距，也不依赖添加更多案件来填空。

- **A 角色邀请**：左侧人物组合和一句产品说明，右侧明确案件入口；一案是一张集中主卡，两案在右侧纵向排。更突出轻松品牌与人物邀请感，但首页人物组合容易比案件抢眼，未来较多案件要继续考虑列表延展。
- **B 故事封面（推荐）**：案件本身是主视觉；一案是横向宽幅卡、两案分两列，手机自然纵向。封面与案情、入口组合紧密，人数与案件数量变化更自然；代价是后续需要为案件公开形象/原生封面排版配置确定范围，不能把某一套三人组合硬编码到通用首页。

## 范围与内容

保留正式B黄蓝/深蓝轮廓、正式Logo、暖白阅读面与A对话页同套按钮语言。只保留一句产品说明、必要案件摘要、当前询问预算与“查看案件”操作。按钮是静态样例，不启动真实服务；选定后沿既有首页→接案→调查与离开确认，不在本稿重定义确认/持久化规则。

第2案《压轴怎么是鸭叫》是尚未批准内容的**设计占位**，仅引用公开提案“四人木偶剧谢幕曲变鸭叫”的一句摘要；所有双案稿明确标“筹备中 · 设计占位，未上线”，没有进入按钮，不注册到游戏，也没有编造预算/角色信息或称已可玩。待第二案批准后再替换正式公开内容。

素材只引用现有 `../brand/logo.svg`、`../appearances/assets/` 下3张默认人物PNG；没有重新生成人物或编辑原图。B第二案封面只是原生CSS帷幕/问号几何占位，不是已批准案件插画。`build.py`可重建4份静态HTML，`home.css`为共同原生样式。

## 实际验证与限制

内置浏览器逐页查看两版单/双案。高层viewport根据当前浏览器75%缩放补偿后，DOM实测桌面1280×800、窄屏391px：八组合全部图片加载完成、document scrollWidth=clientWidth，无水平溢出，人物脸/头发与中文完整。窄屏两案允许文档纵向滚动，A高851px、B高1021px；没有把后案挤进首屏或隐藏案件说明。

截图是原生IAB fullPage JPEG，没有脚本裁图、缩放或改像素。受当前75%浏览器缩放，**实际文件**桌面为1707×1067；移动为520px宽：单案两版高1125，A双案1133，B双案1360。文件有额外黄色外沿，实际布局宽度以上述DOM测量为准；不把截图物理像素冒充CSS视口。CDP截图校准曾异常长时间阻塞，之后停止该方法，用原生截图完成；临时viewport已reset，未更改用户浏览器缩放设置。

本轮仅静态视觉方案，不跑与此无关的应用/语音测试，不声称已实现新版首页。没有新增分类/搜索/榜单/账号、头像选择器、证据、文字输入或新玩法。没有触碰当前运行页面8787或麦克风。
