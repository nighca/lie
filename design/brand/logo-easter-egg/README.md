# Logo 小彩蛋：设计提案

**探索提案，未批准。** 2026-10-24。用户授权独立 subagent 先设计；本目录没有生产实现、已激活素材或新玩法。本轮建议只选一个效果，不叠加三个方案。

## 设计基线

沿用已批准的 [正式 Logo](../logo.svg)（B 微调 `shorter.svg`）：深蓝 L/E、蓝色 i、珊瑚红圆点，置于既有中文 B 黄蓝页面。静止时路径、配色、比例和“语音推理”标签完全保持现状。彩蛋来自字标的小动作，不增加吉祥物、声音或答案暗示。

目前 [ProductHeader](../../../packages/ui/src/components/ProductHeader.vue) 中整个品牌区是一个 `href="/"` 的链接，点击交给 `navigateHome`。设计必须保留这个入口及既有离开调查确认流程；彩蛋不替代首页导航。

## 三个候选

以下幅度按目前桌面 105×56 CSS px 的 Logo 标注，移动端 88×47 等比缩小。数值用于限定克制程度，仍是待选方案参数，不是生产规格。

| 方案 | 看见什么 | 时间与幅度 | 判断 |
| --- | --- | --- | --- |
| A · 圆点装镇定（推荐） | i 上的红圆点轻轻跳一下，落回原位，像刚被问到时一瞬间的心虚；其他笔画不动 | 共 560ms，最高上移 3px；末段不二次弹跳 | 最小改动，保留字标识别；不依赖文字或人物表情，符合轻松推理气质 |
| B · 大家看向 i | L 和 E 各向中间微倾，红点原地停住，再恢复；像旁边两个字母偷偷看过来 | 共 680ms，L 顺时针 2°、E 逆时针 2°，以各自底部为轴；无位移 | 更有情节，但 105px 小尺寸可能不如 A 清楚，容易被看成普通 hover 动效 |
| C · 小声补一句 | Logo 不变，旁边暂现小字“我可没说谎。”，随后消失；像字标自己忍不住插嘴 | 共 1400ms：120ms淡入、1160ms停留、120ms淡出；不移动字标 | 最直接可发现，但增加了品牌说话的性格与新文案，比 A/B 更强，需明确认可这句语气 |

### A 的动作分镜

| 时间 | 圆点 | 其他元素 |
| --- | --- | --- |
| 0ms | 原位 | 原样 |
| 150ms | 上移 3px，保持正圆 | 原样 |
| 360ms | 回原位 | 原样 |
| 560ms | 原位，效果结束 | 原样 |

不拉长鼻子、不做真假颜色切换、不让任何人物响应；“心虚”仅是字标的幽默读法，不表示某个角色有罪。圆点位移须留在原 SVG viewBox 内，不扩张链接布局。

## 共同交互约定（提案）

- **鼠标**：进入品牌链接时播一次；悬停不循环，离开后再次进入才可重播。点击仍立即走原首页行为，不等待动画完成。
- **键盘**：Tab 聚焦品牌链接时播同一个效果，保留可见 focus ring；Enter 立即走原首页行为。不增加 Tab 停靠点、隐藏快捷键或双击要求。
- **触屏**：在原品牌链接上按下时提供同一效果，不要求长按；轻触仍执行原导航，拖动/滚动按浏览器原规则处理。导航可能让彩蛋尚未播完就消失，这是可接受的，不为看完效果而拦截点击。
- **避免重复**：同一轮指针/聚焦交互只播一次，点击不额外排队；播放期间新触发忽略，不累计旋转或位移。失焦、离开品牌区或组件卸载即恢复静止，不落盘、不跟踪次数。
- **调查离开**：沿用现有确认；取消确认仍留在原局。不能为触发彩蛋额外调用导航、重置会话、停语音或修改计时。
- **导航语义**：仍是单一首页链接，可访问名称保持“LIE 首页”；保留浏览器中键、新标签页和右键菜单等原行为。图形装饰不改成按钮，也不在链接内嵌按钮。
- **无循环与自动播放**：页面载入、角色发言、指认结果均不触发；不读取麦克风或游戏答案。

C 的文字只作非交互装饰，`pointer-events: none`、不挡标题或操作；不能改变布局宽高。无足够横向空间时改为品牌区下方的局部浮层，仍不遮控件；若无法满足则不采用 C。文字不作为必读状态，不用 `aria-live` 打断转写朗读；首页链接的名称不被文案替换。

## 减弱动态与窄屏

系统 `prefers-reduced-motion: reduce` 下，A/B 不移动、不缩放、不旋转，替换成圆点外一圈静止深蓝细描边，展示 560ms 后直接撤去；描边只在图形内绘制，不抢代链接 focus ring。C 直接出现/消失，取消淡入淡出。用户在停留期间切换减弱动态时，立即停止运动并恢复静态。

移动端保留现有品牌触区，不把窄屏约 9px 的红点做独立目标。三方案均无音频、震动、闪烁、持久徽章或自动弹窗。键盘和触屏都能触发同一趣味反馈，但正常导航可以先完成。

## 建议与待确认点

建议选 **A · 圆点装镇定**：只动现有一个几何元素，不引入品牌人格文案，最容易在现有页眉与窄屏中保持安静。保留这次“碰巧发现”的程度，不增加提示引导或完成奖励。

请由视觉 owner 与用户确认：

1. 选 A、B、C 中哪个（或暂不采用）；这次只选方向，不代表三个一起实施。
2. 是否接受“鼠标经过/键盘聚焦/触屏按下即触发”的轻量发现方式。推荐不采用连点次数、长按或秘密按键，这些会与首页入口争夺动作。
3. 仅选 C 时，再确认“我可没说谎。”的文案和字标开口说话的性格；A/B 无新文案。

批准后再交生产实施。A/B 可能需要把当前 img 载入方式换成可定位字母的 SVG；须保持正式路径与可访问名称，不重绘 Logo，不动 favicon，也不把静态品牌资源整体替换成动画资源。这个实现选择留到批准后的 scoped review。

## 后续验收清单

实施 owner 需要在独立工作树完成以下核验，root 负责组合 review：

- 桌面 105×56、窄屏 88×47 字标与静态基线一致，动画无裁切、位移不引发布局变化；391px 无水平溢出，品牌与页眉操作不重叠。
- 鼠标进入、连续悬停、离开重入；Tab/Shift+Tab 与 Enter；真实或模拟触屏轻触、拖离取消都保留原导航语义。
- 首页/编辑器/调查页点击入口及调查离开确认、取消行为均保留；新标签页行为不被彩蛋改写。不使用真实麦克风验动效。
- 减弱动态与运行中切换偏好，卸载/快速来回聚焦无残留、叠播、额外计时器或音频。
- 若采用 C，额外验窄屏浮层不遮操作，辅助技术仍读“LIE 首页”，不新增播报或 Tab 项。
