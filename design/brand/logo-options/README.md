# Logo 候选方向

状态：四个候选均未获批准，仅供用户选择方向；不替换现有 `design/brand/logo.svg`、横幅或应用。沿用已确认的中文 B 配色与轻松游戏感，本轮探索的是品牌图形结构。

主交付 `comparison.png` 是 1440×1047 的中文对比板，可直接展示。`index.html` 是其可编辑排版源；各子目录含 `logo.svg`（横向完整标志）、`icon.svg`（简化图标）、`mono.svg`（单色完整标志）。`build.py` 是原创几何绘制源，可用 Python 标准库重新生成 12 个 SVG；未使用 AI 位图、字体、外部图片或第三方图标。

| 方案 | 名称 | 结构与取舍 |
| --- | --- | --- |
| A | 会说话的字标 | 以不规则圆润 LIE 为主体，i 的圆点带表情。品牌名最直接；小图标保留表情与竖笔画。缩小时表情是辅助，不能依靠眼嘴细节独立传意。 |
| B | 对话碰碰 | 两个方向相对、彼此交叠的气泡，搭配圆润字标。强调对话，符号适合导航与分享；单色保留前后气泡区分。 |
| C | 小话团 | 原创气泡轮廓小角色与蓝色字标，可拆成独立符号。亲切、可延伸，但角色化程度最高，需用户确认是否希望品牌拥有此类形象。 |
| D | 字母碰碰乐 | 三块独立倾斜的 L/I/E 积木，强调轻松游戏感。小图标只保留首字母 L 的积木，避免三字在极小空间挤压。 |

本轮“小图标”展示约 43px 与 25px 两档，单色使用深蓝与留白，不依赖灰度差。没有直接把完整标志缩成 16px favicon；选定方向后再按实际平台像素与安全区精修。所有 SVG 均为自包含可编辑路径，透明背景；尚未制作反白、商标注册检索、应用图标各平台规格或完整品牌系统。
