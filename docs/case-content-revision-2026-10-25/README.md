## 贺宁为什么原来容易承认

[上一版完整回答指导](he-previous-response-guidance.txt)保留备查。主要风险是：

1. “初次笼统问……可以回避”只约束第一轮，后面反复问不再受保护。
2. “强调只是想让节目好一点”与开场“大家不是也笑了吗”很容易变成承认动作后的动机辩解。
3. “持续追问后承认换曲”容易把轮数或压力误作揭晓条件，即使中间没有得到具体事实。

修订把归责和亲历分开：打招呼、直接指责、重复施压、假称别人已认都不该触发自曝；具体问短试听、谁留台、后来去了哪里仍据实回答，不把“待在台旁”偷换成“主动承认换曲”。有事实支撑的连贯推理后，可以为临时加笑点辩解及承认具体操作，不规定固定口令、问序、完整逐字时间线或轮数，不要求自白才能指认。没有改 generic system prompt 或引擎，没有新增程序性信息解锁机制。

备选“始终否认任何操作”未采用，因为会堵住正常询问与既定可解性；备选“问够几轮后认”未采用，因为会鼓励磨自白而非交叉核对。当前自然语言指导是否被真实模型遵守仍是未验证假设。

## 逐案人工一致性检查

这是作者对照三案 11 份人物设定与结局的人工审查，不是真实 AI 发言或陌生玩家盲测。

- **纪念章**：沈禾亲眼见章并直接交顾遥；沈禾/陈拓共同在前厅，摄影间进出由亲历可问；陈拓在房内交接台旁与顾遥共同见盒已空。这些把取走窗口落在顾遥独处保管时。装饰纸带不等于封签，小秘密分别是授权开盒和检查空盒，责任仍为顾遥。删公共排除句后，“同一盒”和必要出入条件没有从角色资料消失；没有依赖包内藏处才排除其他人。
- **鸭叫**：任爷爷的合排钢琴→周乐/贺宁合排后短试听仍钢琴→周乐去幕布组后不回→贺宁随后离台→乔姨从此持续观察无人触台→任爷爷只调小音量按原键。任/乔/周三人的口径共同划定贺宁独处窗口，不需要贺宁自白或知道其他人的私下想法。贺宁仍如实回答自己的短试听和位置；不新增第二次换曲/其他设备/旁人目击。动机与鸭录音来源可在结局揭晓，不作为唯一性事后补丁。
- **盐糖**：老师完整两次说糖四盐一，仅阿湛听；岚/余都听阿湛整句糖一盐四；两人各自加对应数量并相互看见，之后只搅拌。原配方和实际分工不相同，责任仍为阿湛的传话次序颠倒；无需用咸味倒推出精确勺数或引入常识配方。勺大小/刮平/没有补料由亲历仍能核对。陶老师没有变成看见全程或“检验排除一切”的全知人物。

其余责任人口径风险：顾遥也含“初次问”“持续准确追问后承认”，但限定准确窗口推理，并明确不因直接认罪要求立刻讲全部，仍建议后续真实模型一起回归；本批不顺手改变她的人物策略。阿湛的承认是对照本人听到/说出的两个数量口径，属于无心记反；“第一次泛问”措辞有同类弱风险，但尚无此案过易认的实玩证据，未擅改。三案其他人物原来的“具体同义问要答”保留，避免把角色小秘密强化成死结。
