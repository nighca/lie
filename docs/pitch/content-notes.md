用户反馈：既有品牌合适，但页面形式中规中矩，需要减少平铺文字，增加图形图像与冲击。下表是待制作验证的方案，不代表新的游戏 UI 或已批准成品。每页用一个可辨识的视觉事件承担叙事，避免把不同文字表格都套上角色装饰。

| 页 | 视觉主体与动作 | 文字压缩与事实边界 |
| --- | --- | --- |
| 1 | 正式 LIE 字标占大幅画面，一张现成人物立绘以近景从边缘进入；黄底、蓝字形成强对比。可短暂切入已有横片 0–5.8 秒品牌段，但不重复整片。 | 只留标题与“轻松开口，认真推理”。不让封面承担功能清单。 |
| 2 | 播客开场：用真实预设小周blue-glasses、小陈plum-crop两位人物与公共背景，显示“两位嘉宾，一位本地人”，把“你会先问谁？”作为进入现场演示的邀请。 | 小周男性、小陈女性，不交换形象或身份；不展示私设、答案、预编对白，也不以地域梗判断现实人物身份。 |
| 3 | 先由本地演示页切到江苏案，现场开口，90秒内返回；现场不可用则播放原纪念章28.5秒备用实录，展示前明确换为另一历史案件。 | 备用原片13.5–42.0秒有实际玩家与角色声；不能把纪念章问答配在江苏人物画面上，也不能为江苏案编造已验证回答。新宣传片与真实备用片分开。 |
| 4 | 使用已有首次帮助真实截图放大时间问号/四段说明与指认后果文字，突出玩家决策前知道规则；不堆完整网页缩略图。 | 不改计时或指认语义；打开说明不暂停，点击人物立即结束，选错不揭答案。截图不作Safari语音已修证据。 |
| 5 | 已有WebMCP入口、实操说明与真实填稿验收截图承担前后对照：讨论意图可进入同一表单，而非逐字段搬运。可配一处表单字段放大；不新增现场工具试验。 | 标为已有特定来源验收与虚构样例，不冒充当前实时Agent在线。助手有支持能力才用工具，普通表单一直可用；不假装一次写稿就保证好玩。 |
| 6 | 六案数量与真实标题/首页，配已有可复用形象，保持“作者可复用资源”的视觉重点。 | 江苏第一、徒步第二，徒步正式名《这条线你真走了吗》。数量是内容规模，不是用户规模。 |
| 7 | 两条平行职责链：游玩为浏览器→薄网关→语音模型，创作为用户Agent→WebMCP页面工具→当前表单/本地保存。两条均回到用户体验，避免文件树与全模块蜘蛛网。 | 明确程序判定、模型表达；创作链无产品侧新模型服务，不把WebMCP与游戏语音MCP上下文工具混成一条。更多Agent适配是方向，不画不存在的已适配平台Logo。 |
| 8 | 用真实编号案件 JSON 的公共字段裁图、八形象清单缩略与一套真实动画部件/运行帧作三个先后镜头。把同一形象在官方案与作者试玩中的复用对应起来，体现统一规格的实际效果。 | 标题“一份内容，进入同一个引擎”。不要求观众阅读代码，代码只露出标题/人物/形象引用等少量字段，隐藏答案。 |
| 9 | 从同一案件的公共背景开始，随后每次只展开一个角色的个人资料截取，再显示该角色的对话历史，最后回到其游戏立绘。可用可编辑简图或实际资料裁片表达“每次只给这一个人的资料”。 | 避免并排展示所有角色全部设定而让人误以为一起送入模型。不要编对白做所谓信息差实证。若引用 profile，截取非剧透、能理解的片段。 |
| 10 | 一套人物的制作“实物”铺开：已有生成源图、拆分部件、动画轨道/运行帧与真实游戏落地画面，按制作顺序逐项揭示；末尾以真实 Git diff/测试或集成记录局部作为审查证据。 | 少讲抽象“全流程 AI”。一句话说明人类做决策、Agent 做执行与验证；不展示 token/工时倍数。制作中若缺某一阶段原始资产，删该阶段，不能补画成既有证据。 |
| 11 | 大尺寸试玩二维码＋正式域名，占主要视觉面积；角色回到开场那一位，保留“你会先问谁？”形成呼应，其他页面元素退场。 | 二维码必须解码核对正式入口。此页停留问答，不塞路线图。 |

执行建议：每个主讲页最多一个主论点，完整细节移备注和问答附页。图像应承担“发生了什么”“哪里不同”“如何复用”之一，角色只在承担剧情、资源或品牌作用时出现。转场使用出现、替换与局部放大即可；没有播放器支持的动画也要让 PDF 的最终静态画面独立可读。现有设计稿中的原型占位不能作为当前产品截图。
