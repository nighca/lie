## 为什么用四人

四人能让两个阶段的亲历分别来自不同人物：有人确认合排后仍是钢琴，有人描述换曲窗口，有人说明正式播放前只动过音量。相比首案的三人交接与物品失踪，这次是舞台小恶作剧，核心区分“调整音量”和“改变播放内容”，而非找物品藏在哪里。

新增一人也会增加语音时间和记忆负担。因此建议角色称谓鲜明，不要求记分钟数；用“合排后”“取胶带前”“正式开场前”即可讨论。四人是本案候选规模，不是通用玩法的新限制。具体形象待用户选案后从素材库匹配；本轮不预设尚未完成的形象可用，也不新增制作需求。

## 剧透：固定真相与关系

**实际换曲者是贺宁。** 她负责木偶动作排练，觉得鸭子木偶没有得到足够掌声，想把谢幕临时改成鸭叫逗大家笑；她误以为观众笑了就不会有人在乎没商量。她在最后一次合排之后，将播放键对应的钢琴录音换成自己事先准备的鸭叫录音。不是误触，不是共谋，也没有第二次换曲。

任爷爷是剧社发起人，乔姨负责服装道具，贺宁负责动作排练，周乐是负责播放台的小帮手。四人都是成人；周乐是刚加入剧社的年轻成人。任爷爷与乔姨是老搭档，贺宁和周乐分别带排动作和播放音乐，彼此熟悉但不需要玩家掌握既往关系。

“播放键对应的录音”只是一项故事事实：不要求玩家理解文件格式、软件、音轨或快捷键。角色能用“把按下去会响的那段声音换了”解释。玩家不需要查看播放台、试听素材、读取操作记录或识别真实鸭叫才可解案。

## 只靠对话如何排除

第二次短试听将“还没被换”的时间放在合排之后，而不只靠大家对合排的共同回忆。周乐离台后持续与幕布二人一起，不能在该窗口换曲；任爷爷和乔姨也在幕布组。贺宁是唯一留在台边的人。

乔姨对贺宁离台后的持续观察与任爷爷的具体操作，把另一个窗口封住：正式播放前没有别人接触播放台，任爷爷只改音量，音量不改变内容。所以“最后按键的人就是换曲的人”不能成立。两段亲历合起来，实际改内容只可能发生在贺宁独处阶段。

这依旧依赖故事人物遵守其固定亲历；不证明全员串供不可能，也不承诺口述能提供司法级验证。四人不得为了临场回答创造合谋、另一键、预设自动切曲或新操作者。若玩家不接受任何口述，当前玩法没有另一个搜证通道，不临时补出来。

### 路径一：先问最后按键的人

1. 任爷爷：“你按之前做了什么？”——可先说照常按，具体追问后说明只调小音量，再按同一播放键。
2. 乔姨：“你看见他换东西或换曲了吗？”——讲自己看到的旋钮与原键；同时说明贺宁离开播放台后到那时无人再碰过。
3. 周乐：“合排后你还有没有碰播放台？”——承认和贺宁短试听了一次，仍然钢琴；然后离开取胶带。
4. 贺宁：“他走之前你们听到什么？”——确认钢琴，随后自己留在台旁；不能把鸭叫推到那次试听。
5. 乔姨或任爷爷：“周乐拿了胶带就回去了吗？”——说明他一直留下固定幕布，贺宁离台后也没人返回。
6. 玩家选贺宁。她无需先说“是我换的”，固定责任人判断不依赖认罪。

### 路径二：从鸭子木偶的误导入手

1. 乔姨：“鸭子为什么在前排？”——承认自己临时换摆法，想拍照；这只改变道具位置，不是音箱内容。
2. 乔姨：“你什么时候看见贺宁到前排？”——讲她从播放台走来，之后自己持续留意那一侧直到任爷爷去播放。
3. 贺宁：“你在播放台时，周乐在干什么？”——先有一起短试听，后来他取胶带，自己独处；不主动倾倒换曲计划。
4. 周乐：“你离开时是什么声音？之后去哪？”——钢琴；到另外两人面前拿胶带并留下，未回台边。
5. 任爷爷：“当时你和谁在一起？正式放的时候换了什么？”——幕布组的三人关系；正式放时只调音量按原键。
6. 玩家排除“摆鸭子的人”与“按播放的人”，选贺宁。

## 误导与漏洞检查

- **任爷爷最后按键，看起来最可疑。** 他的具体操作与乔姨目击互相约束；公共背景明确音量不换内容。不能靠“老人不会操作”排除他。
- **周乐承认额外试听，看起来乱碰过。** 但贺宁同样听见那时仍是钢琴；他之后持续在幕布组。不能靠“试听就是改曲”指认。
- **乔姨改了鸭子木偶位置，像是提前安排笑点。** 只是视觉摆法；其后一直在幕布组，她没有音箱操作机会。鸭子本就在剧中，没说摆鸭子必然有鸭叫。
- **贺宁说鸭子属于节目，是否说明改曲获准？** 原定谢幕钢琴已公开，其他人未同意改动；她的辩解不改变未经同意的行为。
- **曲目变了是机器故障／自动切换？** 公共背景限定没有自动切换、远程设备；正式设定应通俗说明，避免将技术推断留给玩家。若作者需要再加大量设备规则才能讲清，应简化本案而非增加软件机制。
- **拿胶带前周乐已经换了，只是试听另一键？** 短试听与正式播放明确同一键，双方亲历一致；不能临场新增另一键或另一播放模式。
- **贺宁离开后有人偷改？** 乔姨的连续观察覆盖这一段；正式文本不能退化成含糊的“好像没人来”。
