# LIE 视觉方向：轻松的推理游戏

更新：2026-10-23。用户已确认方向偏好；具体风格稿仍待确认，暂不展开正式设计。

## 用户的新方向

此前的夜间审讯室、明亮访谈台两套风格均被用户否决。用户喜欢多邻国的风格：简单、轻松、亲切，适合首版轻量游戏。视觉不必强调传统推理题材的严肃与紧张；与题材形成反差，可以成为产品辨识度。

本轮将这一偏好转成待评审的设计：明亮背景、鲜明配色、圆润按钮、表情丰富的卡通成人角色，以人物和语音为中心。参考亲和力与交互反馈，LIE 自己的配色、字标和角色仍需建立。无须增加积分、爱心、闯关地图等机制来获得游戏感。

## 确认后推进

专门的视觉负责人统一 UI、字标、人物和演示物料。用户确认新稿后，先将其转成可实现的色彩、字体、间距、按钮与语音状态规范，再按已确认原型设计接案、审讯、指认与结局页面。人物数量由数据驱动，不把三人固化成背景图。

正式版只使用自由语音与操作按钮，不提供文字输入、证据、可信度或其他未经确认的玩法。视觉表情不能充当系统判定“此人正在撒谎”的提示；语音状态用真实事件驱动，不能用动画编造平台没有提供的识别阶段。

实现时验证中文排版、按钮可读性、键盘焦点、缩放和减少动态效果。颜色之外同时使用文字或图标表达状态。假数据测试覆盖麦克风失败、等待、打断、切人和错误恢复；真实设备验证收音与播放。总体风格确认与模块架构确认仍是不同关口。
