# 顾遥原画分层关节动画：单角色验证

起点 `3bf89144863038b90899d0e82f31760c971de37b`。本轮用户已批准继续原画拆层与骨骼动画验证；**这仍是独立样片，不是获准替换生产人物的最终素材**。不改变2D主线、3D研究、案件或语音服务，不批量制作其余角色。

## 结论

原画风格可以进入分层关节动画：六个透明PNG分别提供头、颈/躯干/裤、左右上臂、左右前臂含手，前臂作为上臂的子关节运动。静止和小幅动作保留了原画的脸型识别、深蓝发丝、耳饰、珊瑚衣服与阴影细节，较此前SVG简化稿更接近已有素材。**但它不是原PNG的无损自动拆分，也没有达到正式接入所需的静止轮廓和关节精度。** 当前适合让用户判断方向和动作范围，不建议据此宣布八套素材已可低成本生产。

原生Canvas的层级变换足够展示这个有界样片，无需先购买或安装商业运行时。它证明的是“独立位图层＋肩肘铰接”能工作；不证明大动作、网格蒙皮、任意转身、衣袖连续变形或中文口型已经解决。

## 制作与来源

1. 实际查看批准原画 `design/appearances/assets/coral-bob.png`，并读已有2D选型/近似SVG样片。没有用SVG重绘人物或直接漂浮整个PNG。
2. 使用内置imagegen按原图引用编辑，共**8次有界调用**：头1、躯干1、躯干去袖修正1、四个臂段4、右前臂alpha清理尝试1。未切CLI、未安装工具、未上传到额外素材平台或购买运行时。
3. 第一次躯干仍带完整袖子，被判不适合独立上臂；修正后去袖并保留独立颈部/中央衣服/裤子。第一次右前臂带低alpha边缘雾，一次清理后仍不能称完美干净。两次原始尝试均保留，不把失败藏掉。
4. `sources.json`记录每次完整原始输出路径、edit reference、prompt、SHA256、尺寸/字节/透明检查。`prompts/`是实际传入文本；生成结果只复制，没有Python裁图、抹背景、缩放或像素重绘。
5. 生成器没有稳定遵守“原画幅/原位置”：输出从1024×1536到1254²等不等，头等部位也被重新放大。因此通过Canvas逐层配准恢复原位。六层运行时解码前PNG合计 **3,510,405字节**，尚无图集或生产压缩；不能把这个原型当最终包体预算。

所有输出为RGBA，alpha最小值0，头/躯干/袖/左前臂最大255，右前臂最大254，保留实际alpha未强改。显著alpha边界与低透明杂边不等同；本轮没有脚本清理这些边缘。

## 绑定与动作

1254²舞台使用固定坐标，头绕颈部转，左右上臂绕肩转，前臂嵌套于对应上臂再绕肘转。躯干保持固定，没有把整图上下浮动冒充关节运动。先绘前臂再绘袖，再以中央躯干遮挡肩部内缘，最后绘头；圆润肘帽藏在袖口内。它是刚性图层铰接，非网格蒙皮或IK。

| 图层 | 原始图像到舞台的配准 |
| --- | --- |
| 躯干 | x100/y174，scale0.85 |
| 头 | 静止x250/y15，scale0.56；颈枢轴650/395 |
| 左上臂 | x308/y394，scale0.33；肩480/480 |
| 左前臂 | x204/y692，scale0.34；肘456/770，跟随左肩 |
| 右上臂 | x585/y430，scale0.4；肩850/490 |
| 右前臂 | x749/y813，scale0.28；肘845/850，跟随右肩 |

原位角度全部0；待机只让头/肩肘做小幅独立摆动；聆听轻偏头和收拢前臂；说话前臂向外小幅屈肘，避免手被躯干遮挡。说话头最大约1.1°、前臂约±15–16°，不用大幅甩臂掩盖接缝。状态目标平滑靠近；暂停/时间轴可检查指定相位，减少动态效果时停止循环摆动。眼嘴保留原画，不伪造嘴部动画或音频联动。

## 实际视觉判断与限制

- 初次拼合曾有颈部白缝和明显高出的右肩；已实际在IAB查看并调整头部重叠、右袖位置。现小角度下人物整体完整，头发、脸、双手与原画下缘取景都可见，没有明显分离的肢体。
- **静止仍有近似**：头部面部细节与身材/衣袖轮廓不是原图像素复制；两侧袖口宽度、肩线和手掌大小有差异，右肩与衣身内缘存在硬接/叠线感。颈部在较大转角可能再露缝。不能把“加载6层”视作美术通过。
- **动态仍有切片感**：手指保持原画放松形状，屈肘只是移动这只手，不会自然变成掌心朝上/指向动作；袖口没有布料变形。大角度会暴露被遮挡端点、重影或手臂穿过躯干，所以只做小手势。
- **边缘仍需修整**：右前臂低alpha雾/轮廓粗细与其余层有差异；大图和不同底色需人工审查。若要正式生产，建议在可编辑分层源中补画/修边、统一接缝与手型，再评估是否需要网格工具；本轮不未经批准增加商业依赖。
- 本轮没有拆眼/嘴、眨眼或口型，不提供完整转头/背面；不能直接从这六层推得用户想要的全部状态表情。

## 可复用成本

样片的Canvas父子关节、状态切换、暂停/定格和对照页可以复用；每个人物的分层资产、隐藏补画、比例/枢轴、遮挡顺序与动作幅度仍需分别制作和验证。本次已用8次图像编辑加多轮实际配准；未证明其余七人可以“一键”完成。当前下一步应先由用户看本角色原画保留与小动作是否符合预期，再决定修到生产精度/改用专门分层工具；不自动批量扩充或替换运行时。
