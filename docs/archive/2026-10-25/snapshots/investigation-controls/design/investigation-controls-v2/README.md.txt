# 调查控制区 · 第二轮候选

本轮待用户确认视觉方案，未修改生产 UI。既有调查 A、中文 B 品牌、人物素材与玩法保持。

## 直接查看

先在仓库运行 `node scripts/appearances.mjs`，再从仓库根目录启动静态 HTTP 服务。

- [玩家讲话稿](index.html?state=input)：默认展示明显连续收音波形，不必先找状态菜单。
- [角色回答稿](index.html?state=output)
- [关闭稿](index.html?state=off)：两路灰色静止，不伪造录音。
- 其余状态可通过画板上方的模拟状态菜单查看，包括双路声音、等待、连接与耗尽。

## 这轮改动

- 案件背景移到人物栏顶部。按钮在人物列表滚动容器之外：桌面置于纵列上方；窄屏占横向 rail 左侧独立 84px 区，不随人物横向滚出。它不会在整页向下滚动后常驻屏幕，这与底栏固定是两件事。
- 对话按钮用品牌蓝色、深蓝描边和下沿阴影，明确“开启对话 / 结束对话”。时间始终在左；状态与按钮构成主体。
- 右侧指认独立较小区域，以竖分隔线、奶油底按钮降低权重。“我有答案了”打开选人面板，仍需点选具体人物才提交，不直接指认当前人物。
- 两路各 24 个连续幅度柱：蓝色收音、青绿色回答；可同时存在。关闭/等待时不凭空跳动。1004px 不隐藏波形。
- 标题使用已确认的“询问记录”；自然时长为“本局可询问10分钟 / 5分30秒”，不展示跨人物共享技术说明。

## 已批准规则（不是本轮重新提案）

打开案件背景立即结束语音并暂停计时；关闭弹层不会自动恢复麦克风，需要手动重新开启。窄屏底栏固定。开启语音期间的停顿、等待和回答都计时；波形安静不表示暂停。

## 技术输入和限制

沿用 voice-feedback 技术提案 `20eb743`：未来玩家波形来自真实麦克风音量，角色波形来自实际播放音频；不能从合成振幅推断情绪/说谎或声称真实 VAD。STT 目前仅有 final 的确认，不能把本稿当作 partial 已接通。

本稿所有振幅、对白和计时为本地模拟，明确标注，不请求录音权限、不播放音频、不调用供应商。`state=input` 是演示入口，不是语音事件。未扩展证据、笔记、文本输入或新玩法。当前三人是假数据，不限制游戏人数。

## 实际验收（2026-10-24）

Codex 内置浏览器独立 5367 标签；未操作 8787 或麦克风。实际 DOM viewport 分别为 1280×800、1004×676、391×844，页面 scrollWidth 与对应视口宽相等，图片全部加载，console warn/error 为空。1004 下控制区 844×132，波形区约273×78、语音按钮140×48，均完整；391 下固定栏高约162px，底缘等于844，背景84×54。

实际点开背景后状态变 off，计时停在06:58；关闭后仍 off、按钮“开启对话”、计时06:58。实际点“我有答案了”出现三人选择面板。实际切换回答/双路/关闭/耗尽，检查波形与标签；330秒文案确为5分30秒。原型模型3项自动测试通过（自然时长、开启态均计时、背景停止并取消准备连接）。没有把假数据验收说成真实语音已通过。
