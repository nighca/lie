# 原画人物动画制作与逐人验收流程

2026-10-24。用户授权：契约和流程确定后，可用subagent并行制作其他人物；先把顾遥接入游戏并验证，再启动下一人物。每完成一人由制作代理自检、发起者review后给用户验收；未验收的候选不自动激活到正式清单，不一次批量铺开八人。

## 1. 任务与来源

发起者指定独立worktree、reviewed base/契约依赖SHA、单个人物owner和允许目录，默认下一人为blue-glasses。源始终从canonical `design/character-presets/assets/<id>/{default,listening,waiting,speaking}.png`读取。先实际查看四态，写明靠耳/托腮/说话等原姿势语义和身份特征；不重新设计脸、服装或画风。

未批准人物的工作放`design/animation-candidates/<id>/**`，不改生产manifest/其他角色/引擎/UI。该目录可含候选package/parts、原生浏览器截图、来源hash、实际prompts和自检记录。批准后由协调者review后迁入canonical animation目录并激活一条引用。用户已批准扩人制作，不等于每个成品已美术通过。

## 2. 位图制作

位图编辑遵循imagegen技能：使用内置imagegen，逐个edit目标先view_image；透明背景请求真实alpha，原输出保留并复制，不用Python或脚本改像素/裁切/抹边/去背景。代码仅控制显示/关节/取样及只读格式、alpha、边界、hash检查，不冒称无损自动切片。

优先复用部件，最小制作集按实际姿势确定：无嘴头、闭/开嘴sprite、无臂躯干、必要的普通臂与姿态专用臂。袖口/肘先保证连接；可把复杂托腮/承托作为一个接触组，不强行拆到细关节。并非每个人都必须有相同部件数。肩/颈/袖口留足遮挡重叠端，头与靠耳/托腮手使用共同父变换。小幅循环不能替代正确的状态姿势。

每人首轮最多10次生成，最多2次针对已定位缺陷的补图；到界仍不满足则交代问题并停止继续重生，先向发起者汇报，不无限叠提示。记录每次真实prompt、参考/原输出路径、是否采用、PNG SHA/尺寸/alpha与局限。不得安装或购买商业工具、注册新供应商、外传素材或擅自扩到另一人。

## 3. 装配与动画数据

按[契约](contract.md)创建独立package.json与parts，Node `readAnimationPackage`及生成器校验必须过。画布、锚点和部件取样靠实际边界配准；不假设imagegen原图幅与内容边界一致。各状态共享资产和稳定rig，轨道只携数值/显隐变化。躯干呼吸、头/肩/肘应可感知又不脱缝；等待和聆听也有微动画。嘴随头，靠耳/托腮受接触关系约束。

各状态的头颈/肩袖/肘/手接缝必须在正负极值检查。状态转换若未做自然抬放，应明确标记缺口；不将淡化重影算通过。真实口型同步、眨眼、网格变形等未完成能力必须分别报告。

制作可使用通用独立预览页运行正式AnimatedPortrait组件，参数指定人物与候选包；页面不连接语音/麦克风。所有特殊人物实现应由数据完成；如果需要改通用引擎，应先报告契约缺口，不添加人物ID分支。

## 4. 自检、review与用户验收

- 自动：契约/资源/实际尺寸/源hash；检查坏路径、缺部件、循环与单次过渡、显隐排他、数据隔离。运行有关测试/typecheck/build，fake成功不等于真实语音/美术成功。
- 桌面与391窄屏：实际播放各态、两个相反相位、切换及中断；看头颈、肩袖、肘、手比例、遮挡、边缘halo和画幅裁切。暂停/恢复、减少动态效果、换人晚到/卸载与静态回退分别检查。
- 独立review：发起者读取实际diff、素材与上下文，不能只看代理总结；若独立浏览器不可用，明确记录谁实际验看，不虚报独立通过。
- 用户逐人：交一个可浏览候选、原静态/动态对照、修正点与真实局限。用户在游戏页验收顾遥；其他人先独立候选验看，获批后再激活并检查游戏内兼容。

干净handoff含worktree/branch/base/依赖/ordered SHAs、来源prompts与hash、检查结果、截图、未验/局限。root协调者唯一主干integrator，不内部PR、不自行main/push、不修改用户8787/设备。未通过保留候选与证据，不覆盖已批准素材。
