# coral-bob 混元模型动画实验

2026-10-24。用户提供模型后授权有限精修和动画探索；不替换正式 2D，也不作未来渲染方案决定。

## 结论

这个模型的静态造型明显比此前程序拼装小样更接近原角色，具备继续探索价值。**小幅倾头、上身和前臂动作已在真实网格上做出，并可在浏览器播放。** 但当前只是一个手工粗绑定的局部动作小样，不是直接可用的完整人物动画资源；眨眼、嘴形、手指独立动作和大幅抬手均未完成。

## 真正验证了什么

- 构造 root、spine、head、左右 upperarm/forearm 共 7 根骨骼，模型增加皮肤权重。
- 待机：脊柱和头部小幅变化；聆听：头部倾斜约 7°，略微点头；说话手势：头、脊柱及一侧上/前臂有独立变化，前臂最大约 25°。不是整个人物旋转冒充关节动画。
- 第一轮按坐标区域配权重把裤子带进手臂，出现明显拉扯。`renders/weight-failure.jpg` 保留失败证据。修正采用局部网格表面距离分区，把手臂与临近裤面分开；最终小幅动作的正面和侧面未观察到同样的裤侧拉长。**这不证明较大幅度动作或任意姿势安全。**
- `check_glb.py` 确认三个导出动画均包含实际变化的骨骼旋转，目标为 skin joints，资源无外部 URI。骨骼结构和动画结果独立于展示页的观看角度控件。
- 独立 Three.js 页在 Codex 内置浏览器实际加载，3 动作切换、暂停和 ±90° 检查正常，控制台无 error/warn。单次本机 localhost 模型加载与解析约 30 ms，1 draw call、49,686 三角面；这不包括 JS 下载和首帧，也不是冷缓存、低端移动设备或公网网络测试。浏览器运行截图见 `renders/browser-front.jpg`。
- 独立页 `tsc --noEmit` 和 Vite build 通过。JS 产物约 587 KB（gzip 151 KB），有 >500 KB chunk 提示；未为了小样做正式分包优化。

## 难点和未验证的能力

1. **身体动作可以做，但不是给文件加个循环开关就完成。** 模型没有现成骨架，当前权重是围绕这个姿势和小动作制作的。抬臂、转身、手碰脸会牵涉夹克、头发和身体相交，需要更完整的肩/肘/手腕骨架与逐区权重修整。本轮没有验证完整 IK、全身动作重定向和发丝物理。
2. **脸部不是现成表情系统。** 模型是单个三角网格、单材质，没有既有眼睑/嘴部 shape keys 或独立眼球/口腔结构合同。本轮没有制作眨眼、张嘴或闭合嘴的形变。若要开口说话，需要先检查并修整嘴周/眼睑拓扑和内部结构，再做表情靶；不能把小幅头部动作成功视作面部绑定已解决。
3. **口型和中文语音同步是之后独立工作。** 需要可用嘴形和音频/音素驱动，当前 SpeakingGesture 仅是说话时可以搭配的身体动作，完全没有声画同步。
4. **美术仍需要确认。** 3D 光照、透视、模型自身表情都可能与当前 2D 卡通风格不完全一致；此次没有增加描边或替换正式页面。应与正在进行的 2D 动画实验直接对比，再选投入方向。
