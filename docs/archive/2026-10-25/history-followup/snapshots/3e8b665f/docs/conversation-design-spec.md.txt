# 对话页 A：实施设计规格

用户倾向「A 人物舞台」，并要求删除不影响理解的解释性文案。本规格将 A 收敛为执行稿；不改变游戏机制、流程或业务状态，不启用仍待确认的四态 v2。基于 `ac5d4e9cdab240df2fba277080abf1a7d9cf8360`，原生静态稿及截图位于 [design/conversation-refined](../design/conversation-refined/README.md)。

## 布局契约

桌面优先，以 1280×720 验收。页面左右/上下 padding 24px，header 64px，header 到主体 20px。主体高 `calc(100vh - 132px)`，最小 500px；低于可容纳高度时允许页面纵向滚动，不挤压主要控制。三列为 `104px / minmax(300px,.94fr) / minmax(420px,1fr)`，列间距 20px；两行为剩余空间/104px，行间距 20px。

- 人物切换条在左列跨两行。卡片宽 104px、头像区约 92px、卡间 12px；名字及选中状态常驻。超过当前三人时列表独立纵向滚动，不能硬编码人数。
- 当前人物舞台在中列上行。仅保留默认形象、角色名字；名字 28px，距图 12px。图容器占可用高度，`img height:130%; top:0; left:50%; translateX(-50%)` 为本批默认素材的参考裁切，不是所有形象通用保证；必须看清完整脸/头发。主题色背景不表示可信度。
- 转写在右列上行。卡片 border 2px、radius 28px、padding 24px。标题仅“对话转写”，20px；下分隔线 1px、padding-bottom 16px，距正文 18px。正文独立滚动，flex 子项必须 `min-height:0`；新增及流式增长沿既定逻辑滚底，不新增滚动机制。
- 声音控制跨中右列下行，高 104px，border 2px、radius 25px，padding 16px 22px。三组：声音图标及状态／剩余时间／单一主按钮。mic 56px、状态 20px；必要打断提示 12px。剩余数字 26px、标签 12px，次要共享说明。主按钮高至少 52px、18px字、radius 17px。
- 连接异常可让声区增高约 30px，底部一行必要错误说明，不压掉重试或退出控制；转写保留。已有 lost/EA02 等真实业务语义优先于静态稿通用示例。

实际公共 UI 可保留既有头像 50px 与气泡尖角规则；静态稿为比较整体密度使用 30px 小头像，不要求为了截图缩小已批准的公共头像或重做组件。消息文字 16px/1.7，speaker 12px；气泡 padding 12px 16px、圆角18px的视觉参考与组件既有可访问性一起验收。

761–1000px 可收窄人物条至 88px、左右列最小240/340px、间距16px，品牌副标可隐藏；760px及以下切换纵向结构，禁止挤出横向整页滚动。

390px：页边16px，header自适应两行（品牌与操作；案名独立行）。主体为文档流：横向可滚动人物条 → 当前肖像与姓名 → 常显转写 → 声音控制，不增加页面/开关。人物卡宽约104px，头像68px；舞台图高220px、姓名24px；转写卡总高380px、padding18px 16px、内部滚动。声区第一行为状态与按钮，第二行为剩余时间；错误说明另起行。窄屏整体允许纵向滚动，不隐藏转写，不把语音条覆盖在内容上。

## 必要文案和状态

删除：“正在和谁聊”“把问题说出来，听听她的回答”“每一句，都可以回看”“只读转写”胶囊及页底常识解释。不用另一句同义副标题补回。

保留：案名、人物姓名、选中标记、对话转写、消息发言人、当前公开语音状态、动态剩余时间、“最终指认”“结束本局”及当前唯一语音操作。开发模拟模式标识仍保留，不能把假回复误呈真实模型结果。

| 场景 | 状态 | 操作 | 补充信息 |
| --- | --- | --- | --- |
| 初始空会话 | 等待你开口 | 开始对话 | 转写空态仅“还没有对话” |
| 连接准备 | 正在连接… | 取消连接（沿用实际可取消操作） | 连接准备不计时 |
| 正在接收发言 | 正在聆听 | 结束对话 | 对方回答时，可直接开口打断 |
| 等待回答 | 等待回应 | 结束对话 | 必须按真实状态展示，不用固定“正在聆听”代替 |
| 实际播放语音 | 正在说话 | 结束对话 | 可直接开口打断 |
| 连接异常 | 实际业务错误状态 | 重试连接或既有恢复操作 | 必要恢复说明；保留历史 |
| 额度用完 | 实际预算耗尽状态 | 沿用既有流程 | 不允许新会话继续计费，不由视觉重定义规则 |

时间显示来源为公开 GameView 的 `remainingMs`，不为视觉新增 total 字段或把 `/08:00` 硬编码到通用 UI。首案 8 分钟总预算仍在接案说明，进行中仅展示“剩余询问时间”与动态 mm:ss、“所有人物共享”。真实连接/失败状态和控制文案应采用既有业务投影，不引入新状态机。

## 素材与实施边界

正式 SVG 使用品牌 logo；当前三角色使用既有默认 PNG。状态 v2、3D 探索、本案秘密、证据、文字输入、情绪推测、首页导航均不纳入本轮。静态稿中的对白为无剧透假数据、按钮不连接真实服务，只有预览脚本将长历史滚至末条。实施负责人持有 App/CSS/公共组件，视觉负责人只写本规格与独立静态文件。
