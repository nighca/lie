# 产品宣传视频：工具链与制作依赖调研

状态：仅研究，未开始制作。调研日期：2026-10-24。

## 授权边界

用户允许提前调研制作路径、工具与依赖；真正制作仍须等用户判断产品成熟、功能稳定后，明确同意开始。本文件不是脚本、分镜、镜头表或制作排期。研究完成、有空闲、工具已装好，都不能自动触发制作。

本轮只读查阅产品文档、官方工具资料和本机工具存在性。没有安装依赖、申请录屏/麦克风权限、录制产品、生成声音/音乐/图像/视频、上传素材或调用收费服务。没有选择最终时长、渠道、横竖版、宣传口径。

## 建议结论

建议首轮采用“真实产品录制 + 本地剪辑”，先验证声音采集链路，再决定是否需要代码包装。现有 Mac 已有 FFmpeg、QuickTime、iMovie，可以承担基础后期；为了直接采集浏览器里的角色声音，OBS 是有官方依据的候选增量工具，不需要先安装虚拟声卡。实际安装与录制须留到制作获授权后。

如果后续需要频繁改文案、制作多尺寸/中英版本，再采用独立 Remotion 制作工程。它不是 Vue 运行时的一部分，不应为宣传视频给游戏引入 React、渲染服务器或数据库。AI 生成素材只作为可选补充，不是首版必需依赖，也不能替代真实产品的功能演示。

以上为工具链建议，不代表用户已批准最终制作路线。

## 三条路径比较

| 路径 | 画面与声音来源 | 编辑、转场与复现 | 主要依赖与代价 |
| --- | --- | --- | --- |
| A：真实录制 + 本地剪辑，建议优先 | 在 Codex 内置浏览器操作成熟版本；录屏与应用声音来自真实会话。需要时独立录制真人麦克风，不用外放再收音替代内部音轨 | FFmpeg 可脚本化裁切、拼接、叠字、转码和混音；iMovie 可视化调整片段、标题、转场、音量。保留原始录制与工程后可再编辑，但真实 AI 回答不保证逐字重现 | 可复用本机后期工具；OBS 需后续安装并获 macOS 权限。成本主要是人工验收、重录、本地存储和灵矽真实会话消耗，不要求云渲染 |
| B：真实录制 + Remotion 代码合成 | 演示仍用真实录制；Logo、已确认立绘、中文文字通过代码编排，不重建假游戏来充当实录 | React/TypeScript、按帧编排、字体、字幕和媒体导出可独立版本管理；固定素材与版本后便于重跑。品牌几何与文字转场更可控，但增加工程维护 | 需要独立项目、匹配的 Remotion 包与本地渲染浏览器；现有 Node 不等于已验证整条链路。需核对使用主体许可资格；云渲染非必需 |
| C：A/B + 有限生成素材 | 仅补缺少的装饰插画或非功能性背景，再进入同一剪辑工程；优先复用正式 Logo 和角色图，避免重画导致漂移 | 所生成素材作为固定输入保存；生成本身不保证同结果，可编辑性依赖源文件。字幕、Logo 和产品 UI 仍由代码/剪辑准确排版 | 可能新增账号、额度、上传素材与商业条款核对，应逐项授权。Adobe Firefly 是可调查的商业用途候选，不是已选供应商；本轮未调用或验证质量 |

Apple 官方说明 QuickTime 屏幕录制通过 Screenshot 工具完成，可选择范围、指针等；这不等于已经验证其能直接录到角色的应用输出声音。[QuickTime 录屏](https://support.apple.com/guide/quicktime-player/record-your-screen-qtp97b08e666/mac)

OBS 官方列明 macOS 13 及以上可通过现代屏幕采集源采集应用音频；OBS 30 及以上还有独立 macOS Audio Capture Source。可用于避免“扬声器播放再被麦克风重复收进去”的链路。仍需实际验证 Codex 窗口及音频进程能否按预期单独选中，不能把文档支持当成本机验收成功。[OBS 应用音频采集](https://obsproject.com/kb/macos-desktop-audio-capture-guide)、[屏幕采集源](https://obsproject.com/kb/macos-screen-capture-source)

FFmpeg 的拼接、字幕与音频处理能力以官方滤镜文档为依据，本轮未运行相应处理。[FFmpeg 滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)

## 中文、声音与导出

### 中文字体和字幕

- 当前 UI 使用系统字体栈，包括 PingFang SC。实录保留页面文字；后期独立叠加的中文须检查缺字、字重、标点、断行和最终尺寸的可读性，不把字体名称存在当成完整字符集验收。
- 系统字体可在本机使用，不应直接把 macOS 字体文件复制进仓库或发布包。如需跨机器一致排版，制作启动后再选择有明确许可的可分发中文字体并记录版本；本轮不下载字体。
- Remotion 支持自定义字体并等待加载完成；支持字幕文件的导入、显示与导出，适合维护时间轴明确的中文字幕。它不保证自动转写正确。[字体](https://www.remotion.dev/docs/fonts)、[字幕](https://www.remotion.dev/docs/captions)
- iMovie 提供标题和基础视觉编辑；大量逐句字幕、旁挂 SRT/VTT 的流程须另行验证，不能把“有标题”写成“已具备完整字幕工作流”。[iMovie 标题及编辑目录](https://support.apple.com/guide/imovie/add-titles-mov4d3dce7ba/mac)
- 产品转写可能有错，也没有承诺逐字时间码。字幕须按最终音轨人工核对姓名、关键句和起止时间；必要时输出烧录字幕与独立字幕/文字稿。

### 声音

角色回答应保留真实灵矽会话音轨。玩家真人声音需要参与者同意录制和发布；本地联调的麦克风许可不自动等于宣传用途录制与公开授权。制作时可分离玩家、角色、旁白和音乐轨，避免后期无法调音或重复收音。

旁白不是必需依赖。真人旁白须确认参与者和收音条件；TTS 须另查所选音色的宣传使用权、调用入口和预算，不能从“游戏内可用”推导“可以任意导出作广告旁白”。当前不生成试听、不克隆声音、不购买音乐。音乐/音效可不加；若采用，记录来源和适用渠道许可。

### 清晰度和可编辑性

尺寸与帧率由发布渠道和用户目标决定。本轮只建议保留高于最终输出质量的原始录制，避免低清录制后放大。画幅须同时容纳人物、转写和关键操作，不能只按角色大图裁切而让人看不懂真实操作。

本地导出可评估 H.264/AAC 的 MP4 作为通用播放候选；最终编码、尺寸、帧率和大小均须在目标渠道实际验收。iMovie 支持文件导出和质量/压缩选项，Remotion 有本地媒体渲染接口；本轮没有导出兼容性结果。[iMovie 文件导出](https://support.apple.com/en-ie/guide/imovie/move6e0cb2ad/mac)、[Remotion renderMedia](https://www.remotion.dev/docs/renderer/render-media)

应保留原始片段、独立音轨、字幕、剪辑工程/源代码、依赖锁文件和素材来源。输出 MP4 不应成为唯一可编辑来源；敏感原始录制不因工程可复现就自动进入公开 Git 仓库。

## 本机依赖盘点：存在性检查，不是制作验收

2026-10-24，只读检查标准应用目录和命令版本：

| 项目 | 实际观察 | 对准备工作的含义 |
| --- | --- | --- |
| macOS | 26.5.1 | 满足 OBS 文档所述系统版本前提；权限、实际选源未测 |
| FFmpeg | PATH 可执行，8.0；构建带 libass、libfreetype、libx264、VideoToolbox | 可作转码/字幕候选；没有运行滤镜、导出视频或验证性能 |
| Node | PATH 可执行，24.17.0 | 与现有项目一致；游戏项目未声明 Remotion，不能宣称其渲染环境已就绪 |
| QuickTime Player | 系统应用存在 | 基础采集候选；没有申请录屏权限 |
| iMovie / GarageBand / Keynote | /Applications 下存在 | iMovie 可评估基础后期；另两项不是必需依赖，均未启动或验证版本/操作能力 |
| Blender | /Applications 下存在 | 3D 探索独立继续；宣传视频不依赖 3D 成功，候选样片不能当已上线功能 |
| OBS | /Applications 标准目录未发现 | 若选择应用音轨方案，届时安装；不据此断言其他位置完全未装 |
| 项目依赖 | 根 package.json/锁文件未发现 Remotion | 不应为了此研究修改游戏工作区；如采用，另建制作工程 |

目前不需要用户立刻安装软件、购买订阅或开账号。路线获批并进入制作后，再核工具版本与兼容性；不要提前获取权限或建付费依赖。

## 自动化、许可和成本边界

- 对代理来说，FFmpeg CLI、Remotion 代码工程便于审查差异与复跑；iMovie 时间线通常需 GUI 操作，不能承诺纯代码般的自动化。OBS 也需先完成选源、权限和音轨检查。本轮未安装控制插件或 MCP，基础方案不以它们为前提。
- OBS 官方源码为 GPL；FFmpeg 许可取决于构建，本机带 `--enable-gpl`。使用工具与再分发二进制不同；本项目不打包这些工具，未来若要分发工具链再审核对应义务。[OBS 许可](https://github.com/obsproject/obs-studio/blob/master/COPYING)、[FFmpeg 许可说明](https://ffmpeg.org/legal.html)
- Remotion 当前免费资格面向个人及不超过三人的公司；更大协作主体适用付费许可，制作与自动化产品的计价不同。AI agent 数量不直接当作自然人数，也不能据此替用户判定资格。选择时确认使用主体和当时条款；本轮不要求订阅、不预估固定账单。[许可与定价](https://www.remotion.dev/docs/license/pricing)
- Firefly 官方 FAQ 允许通常的商业使用，但具体功能/模型/账户条款须核对，不能视为排除任何第三方权利的保证。使用平台、上传人物参考、生成付费素材需后续明确同意；不提交社区公开图库。[Firefly FAQ](https://helpx.adobe.com/firefly/web/get-started/learn-the-basics/adobe-firefly-faq.html)
- 本轮没有工时或费用承诺。A 的主要变动成本是真实会话、重录和人工验收；B 增加代码制作和可能的许可；C 增加生成额度和形象一致性返工。依赖和价格应在正式启动时重新核验。

## 用户同意制作后再补齐的输入

1. 用户明确判断产品成熟并授权制作；确定稳定版本、可演示功能和入口，避免拍摄时页面一直变化。
2. 确认受众、渠道、语言、时长区间、横竖版与预算；这些决定画幅、字幕安全区及是否值得用 Remotion，不在研究阶段替用户定案。
3. 确认可公开的无剧透内容、参与录音的人及声音用途；正式 Logo 与已确认角色素材可复用，未验收的 3D、探索稿、未来编辑器等不得暗示为已交付能力。
4. 选定工具链后再安装、获取具体录屏/麦克风/文件权限，验证 Codex 内置浏览器画面与角色/玩家音轨采集。优先沿用内置浏览器，不默认切到 Chrome。
5. 确认音乐/旁白是否需要、供应商和许可；若采用生成服务，确认上传边界与费用上限后再有限验证。
6. 产品和视觉负责人核对字幕、UI、人物状态与正式稿；完成真实声音、导出、渠道压缩和无障碍验收。发布本身另按用户授权执行。

这些是未来开始前的检查项，不是现阶段向用户提出的阻塞请求。

## 真实呈现和无障碍验收原则

真实多轮、打断和语音等待不能靠假对白拼接证明。可剪去重复内容或缩短空白，但不得把非连续会话拼成一次自然实时回答，或把等待变短后宣传成真实延迟；必要时标注剪辑/加速。模拟或概念画面须标注，不能用包装掩盖功能未上线。四态是静态状态切换，不应表现成已实现精确口型同步；3D 样片不等于正式游戏已 3D 化。

旁白/台词配准确字幕，重要非语音声音也按理解需要说明，不能只依赖声音传递关键意思；避免闪烁和难辨小字，保证字幕对比与阅读时间。提供文字稿，必要视觉信息在文字/说明中补充。此处是验收建议，不宣称已达到认证。[W3C 字幕指南](https://www.w3.org/WAI/media/av/captions/)
