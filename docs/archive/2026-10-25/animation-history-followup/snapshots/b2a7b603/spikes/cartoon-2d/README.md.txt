# coral-bob 分层 2D 动画研究

候选实验，不是正式素材或已选技术。没有安装工具、下载运行时、上传素材、生成或修改位图，也没有接入真实语音。

```sh
# 在仓库根目录执行
node spikes/cartoon-2d/check.mjs
python3 -m http.server 5201 --bind 127.0.0.1
```

打开 `http://127.0.0.1:5201/spikes/cartoon-2d/`。必须从仓库根目录提供静态文件，因为右侧参考图引用既有 `design/appearances/assets/coral-bob.png`。没有 npm 安装或构建步骤，浏览器不访问 CDN。

## 实际制作过程与可审查证据

1. 先查看现有 coral-bob PNG，提取识别特征：海军蓝短发、珊瑚色三角耳饰与西装外套、米白内搭、深蓝长裤。没有从原图自动提取骨骼或分层。
2. 在 `puppet.svg` 直接绘制独立 `<g>`：躯干、左右上臂、各自前臂、手、头、眼、闭眼线和嘴。该文件就是本轮完整可编辑源，而非不可复现的渲染结果。
3. 上臂原点是肩部，前臂嵌在上臂的肘部坐标内。`motion.mjs` 输出两个关节的独立角度；改变肩会带动肘，改变肘不会移动肩。这是分层铰接，不是网格蒙皮或IK求解。
4. 四态由明确的角度目标与插值控制；头、眼、嘴是独立对象。嘴形以固定时间周期变化，只用于证明参数可驱动，没有语音能量、音素或真人口型输入。
5. 可显示肩关节原点，暂停或用时间滑块定格检查。低动态模式不自动眨眼或张嘴，保留静态姿势差异。后台暂停累积动画时间，恢复不追赶后台经过的长时间。
6. `check.mjs` 检查四态数值、肩肘确实变化、插值不越界、嘴形随时间变化和低动态固定；同时实际计算五个运行文件的raw/gzip体积。它不替代浏览器视觉或性能验收。

这是代码重绘的**近似人物**，没有达到现有PNG的脸型、发丝、服装阴影和手部精度，不应拿它替换当前角色。袖口、肩部与肘的硬连接可能在大角度时露缝或叠线；没有连续衣袖形变。正式生产需要美术修形或改用带网格的骨骼工具。

## 手工验收

- 切待机／聆听／等待／说话，确认手臂和面部不只整图平移，点击反向切换不闪回起点。
- 说话阶段暂停，用时间滑块比较两个时刻的独立嘴形；聆听有抬手，等待有屈臂，均只是技术姿态。
- 开关关节指南、低动态；调整窄屏，参考PNG仍完整加载且页面不横溢。
- 不请求麦克风，不建立WebSocket，不把页面动嘴称作语音同步。

浏览器验收与测量见 `../../docs/2d-animation-investigation.md`。研究未获得正式接入许可，尚未安装或执行 Rive、Spine、Live2D、After Effects 等编辑器。
