# LIE — 基础链路验证记录

日期：2026-10-23。此记录针对独立技术探针，不代表正式游戏、视觉或模块接口已经获批。

## 已验证的结论

Cloudflare Static Assets + 薄 Worker + 灵矽 WSS 可以在不使用游戏数据库、KV 或 Durable Objects 的情况下打通基础链路。Vue 生产产物与公开 JSON 从同一地址加载，本局示例状态只在浏览器内存中变化。

线上技术探针：[lie-cloudflare-spike.nighca.workers.dev](https://lie-cloudflare-spike.nighca.workers.dev)。页面只有无剧透示例内容，不是游戏交互原型或正式视觉。

| 验证 | 执行方式 | 结果 |
| --- | --- | --- |
| 静态 HTML、JS、JSON、health | 真实本地 workerd + 公网 HTTP | 通过；Worker 仅需 Assets binding，无游戏存储 |
| SPA 深链接、未知 API/材料 404 | workerd 集成测试 | 通过；缺失 JSON 不会被 SPA HTML 伪装为成功 |
| 文本、二进制逐字节回传与正常关闭 | workerd 与公网 WSS 客户端 | 通过 |
| 浏览器本局进度 | Codex 内置浏览器线上操作 | 收集 0 → 1，重开 1 → 0；页面显示 Worker 状态 ok |
| 专用灵矽资源引导 | 真实管理 API、OTA、绑定 | 创建专用无记忆测试智能体和伪 MAC 设备成功，取得设备 WSS token |
| 灵矽端侧 MCP | 真实直连及经公网 Worker 中继的 Node 客户端 | hello、initialize、tools/list、tools/call、工具返回均完成 |
| 文本触发语音合成 | 文档 `listen.detect`，真实模型/工具/TTS | STT、TTS start/sentence/stop 与音频二进制返回完成 |
| 受保护中继 | 同源 Origin + 私密测试访问码，固定灵矽上游 | 未授权请求 403，临时上游凭证不进入静态页面 |
| 类型与离线自动化 | Vue/Worker 类型检查、workerd 集成、协议边界检查 | 前两组分别通过；workerd 5 项、MCP/完整性 5 项 |

当前兼容日期下，Worker WebSocket 二进制默认可能是 Blob；代理两端显式 `binaryType = 'arraybuffer'` 后，逐字节测试通过。代码不使用 Node 原生转码库。

## 实际音频与单次样本

真实协商得到 `pcm`、16 kHz、单声道、16-bit、20 ms 帧，平台返回 600 ms 播放缓冲参数。公网中继样本收到 79 帧、50,560 字节；WSS 建立约 2.49 秒，TTS start 约 7.78 秒，TTS stop 约 9.40 秒，均从客户端开始连接计时。这只是一次包含建连、工具发现和人为等待的协议样本，不是常态响应延迟承诺。

二进制音频已收到和计数，尚未在浏览器解码、播放或聆听。文本触发实验不能证明真实麦克风识别质量。PCM 是本次配置实测结果，不意味着所有音色/模型配置都固定输出此格式。

## 可重复运行与凭证边界

- [Cloudflare 探针](../spikes/cloudflare/README.md)：本地 workerd、生产构建、同域 Assets 和受限中继。
- [灵矽探针](../spikes/linx/README.md)：专用测试资源创建/复用/清理、端侧 MCP 协议与离线检查。
- 实际语音探针必须显式执行，普通自动化测试不读取管理 key，也不请求真实模型。
- 管理 key 只从用户授权的本地忽略文件读取，未提交、未进入页面、未上传此临时 Worker。临时 Worker 仅配置专用设备 token 和独立测试访问码。
- 线上验证完成后撤下临时语音凭证并清理专用测试资源；静态示例与无凭证 health/echo 可以保留供复查。清理结果在交付前更新本节。
