# LIE

现代背景的单人 AI 语音侦探推理游戏。玩家自由审问三名嫌疑人，对照证词和证据，还原预先确定的案件真相。

首发平台为桌面浏览器 Web，使用灵矽提供大模型与语音能力，目标是在 2–3 天的开发窗口内完成可演示 MVP。目前处于产品方案与技术接入预研阶段，尚无可运行应用。

前端使用 Vue + TypeScript，游戏逻辑和本局状态尽量在浏览器运行，游戏内容使用静态 JSON。Cloudflare 静态站点配合薄 Worker 网关，不引入游戏数据库；网关使用 TypeScript，实际 Node.js API 兼容性通过技术探针验证。

产品和技术提案须区分已确认决定、推荐方案及待验证假设。浏览器游戏逻辑维护案件事实和运行状态，AI 只获取当前角色允许的信息；完整 JSON 可被玩家通过开发者工具查看。Worker 保管平台凭据并代理连接。具体模块接口仍待架构评审。

首版交付一个游戏，架构须支持通过新增内容包扩展同审讯玩法的游戏；首案的三名嫌疑人及剧情不能硬编码进通用引擎或 UI。

模块架构初稿须由用户确认后，才开始应用实现。适合自动化验证的模块随实现交付测试，真实 AI 与语音表现另做集成评估。
