# LIE 交互原型

用于确认操作流程的独立低保真原型。全部演示数据在浏览器内，不是正式游戏实现或最终剧本，不连接灵矽、服务端、WebSocket 或麦克风，不请求外部字体/图片。灰度外观不代表已确认的视觉方向。

需要 Node.js 24。运行：

```sh
cd prototypes/interaction
npm ci
npm run dev
```

默认地址为 http://127.0.0.1:5173 。请使用 Codex 内置浏览器查看。

验证：`npm test`、`npm run build`（包含 TypeScript 检查）。

建议体验路径：

1. 接案；自由切换林岚、陈默、周启，各自语音转写记录保留。
2. 用「原型演示控制」选择测试句，点击模拟发言，观察收音、等待、说话状态。可以取消当前一轮或打断，并继续模拟发言。
3. 向不同人物询问不同问题，通过各人的叙述发现矛盾。转写只读，不提供文字聊天。
4. 最终指认：点击陈默/周启触发错误指认，可返回调查；点击林岚则指认正确。
5. 查看完整揭晓，重新开始。

沟通用语音、流程操作用按钮。模拟测试句仅替代真实自由开口，不代表正式游戏的预设选项。没有真实录音、语音播放或自然语言理解；模拟说话开始时完整显示转写。案件、人物回应与简单指认结果均为占位演示。刷新会清除进度，不持久化。不含材料核查或出示系统。
