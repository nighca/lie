## 真实音量接口

复用麦克风现有Float32采样计算RMS，播放器source通过AnalyserNode获取正在播放的信号，不以网络包到达作为播放。独立VoiceFeedback订阅不每帧重发GameView；停止/切人/epoch/出错清零和丢弃晚到。采样至多20Hz；inputActive为局部幅度滞回估计，不是服务端VAD，不改变barge-in、计时或供应商。24柱只展示收到的实际幅度历史，不制造正弦/随机波动。reduced-motion改静态原生音量meter。
