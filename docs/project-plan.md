## 当前阶段与目标

已完成通用引擎、持续语音及三案本地可玩闭环；当前重点是编辑器v2、形象库单一来源、调查控制体验和真实案件质量验证。后续以review过的关键版本集中发布，最终让外部玩家独立体验。

- **本地8787**：已更新首页A、三案、基础编辑/试玩/分享和玩家侦探头像；本地存在不等于线上已发布。
- **线上**：[lie-game](https://lie-game.nighca.workers.dev/)仍为`8cad54ba99160aa578acd68b90ba52c51fa91569`里程碑，含首案三人四态/活动提示/稳定名单；语音已启用，真实合成PCM协议单轮通过，不等于真人完整验收。
- **发布链**：main push后CI通过再部署同提交，CD已有两次真实成功记录；当前本地新功能尚未随线上版本发布。见[持续部署](continuous-deployment.md)。
- **关键质量缺口**：整合版真人麦克风/外放/长会话/盲测、多用户隔离和正式费用硬限额未闭环；fake、文本detect或短WAV通过均不能替代。

## 当前有效决定

| 范围 | 有效约定与来源 |
| --- | --- |
| 产品 | 中文桌面Web、单人语音询问与固定真相；按钮开始/结束/切人/指认，只读记录，无证据/出示/证明组合。初始架构、交互原型均已批准；[玩法](gameplay-proposal.md)、[架构](architecture.md)。 |
| 多案件 | 原“首版一案”已被用户扩展为三案；通用引擎不固定人数，增加同玩法案件只增内容/必要展示配置。首案3人，其余各4人；自编案件至少3人是内容设计原则，不是引擎硬限制。 |
| 数据 | 静态JSON、公共背景与各人物设定纯文本；浏览器可持完整故事/答案，不要求服务端藏案件秘密。形象按ID复用、与故事分离，不从外貌推断心理/罪责。 |
| 技术 | Vue+TypeScript；浏览器运行规则/状态/指认，薄Cloudflare Worker转发灵矽；不默认引入DB/DO/账号服务，管理凭据不得进入前端。Node生态依赖先核Worker实际兼容性。 |

| 转写 | 常显、只读，新增/增长只滚记录内部到底；玩家头像右侧/NPC左侧，历史完整显示，保留中断标记。当前渐显50ms帧/2400ms追赶，新降速与玩家实时文本另见待办。 |

## 当前需用户确认或外部协助

- **调查设计选择**：整体入口/文案、背景打开是否停止语音/暂停计时且关闭手动重开、窄屏固定底栏；这些尚未批准。
- **投稿补验**：用户自行在IAB登录GitHub；未来公开当前源码仓的计划不是现在执行授权。长query失败不能推导短value不支持，登录return_to保真不能当表单成功。
- **公开访问/费用策略**：临时无应用鉴权语音已获线上目标授权，正式访问/并发/限额/资源回收方案仍按用户要求暂缓；邀请/DO/DB未批准，供应商“额度不足可能断开”不是即时硬止付。见[公开语音](public-voice-launch-proposal.md)、[额度调查](linx-quota-investigation.md)。
- **动画效果与扩人**：用户已授权同一coral-bob继续打磨，不需重问单角色启动；第二轮效果满意后再决定扩其他人/正式运行时，不承诺当前样片可直接生产替换。
- **宣传视频严格后置**：仅制作方法/工具依赖研究获准；脚本、分镜、录屏、旁白/音乐、媒体生成和视频制作，必须等用户判断产品成熟并明确授权。空闲/研究完成不替代门禁。
- **真实质量**：新增五声听感、整合版真人/外放和三案盲测仍需实际体验；付费模型复核必须先审脚本/固定矩阵、设单次上限，首FAIL/UNCERTAIN/协议异常停，只清自建资源。
