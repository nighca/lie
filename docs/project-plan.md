## 已确认的产品边界

[模块架构](architecture.md)、交互原型和中文 B 视觉方向均已批准，无需重问。浏览器承载故事、会话和指认，纯 TypeScript core 独立 Vue/宿主；薄 Worker负责Cookie身份、设备与连接准备及分享API，语音由浏览器原生直连provider；已批准的分享方案以私有R2保存静态案件快照，不引入服务端会话/判案，平台管理凭据保持私密。main当前六个官方案人数 2/3/3/4/4/3、共享询问额度 120/360/480/600/540/480 秒（5552215线上静态内容及prod/local健康已核验）；引擎支持可变人数，新同玩法案件只需内容与必要呈现配置，不硬编码案件或人数。旧礼物案未获发布批准，不计入当前六案。
