# 公共背景人物姓名高亮

2026-10-25；主协调明确委派的小范围视觉改进。仅开场介绍与调查中的案件背景弹窗，官方案件、分享链接及编辑器试玩通过现有同一 App 入口受益。未改内容格式、游戏规则、动画/资源加载或作者文本。

## 行为

按当前案件人物真实姓名做精确字面分段；所有出现位置都高亮，重叠优先最长姓名。空姓名忽略，正则符号与 HTML 均按原文。使用 Vue 安全文本节点，不使用 v-html；空白、换行与复制文本完全保留。转写、结果真相和编辑器 textarea 不扩展高亮。

文字保持深蓝，辅以人物主题色浅底、细下划线及字重。没有预设/主题时用同一中性色；预设到达、更新或移除后响应最新值。旧分享中同名人物主题不同或任一缺失时，该姓名保持中性；同名同色可使用该颜色。没有点击、tooltip 或模型识别。
