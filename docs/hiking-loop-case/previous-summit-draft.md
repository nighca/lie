# 被环线版替代的登顶初稿

来源：本chat最初对用户“徒步元素或背景”的提案。状态：用户认为故事整体可用，但明确指出登顶更接近登山，要求调整为徒步；本稿保留，不是本次产品内容或已批准出行建议。替代方案见[当前环线案](README.md)。

## 《这山你真爬了吗》

围绕“假装登顶”展开，既能聊徒步经历，也有朋友之间互相吹牛的趣味。

周末徒步结束，三位朋友围着桌子吃面，都说自己走完了登顶路线。但领队清点时发现，其中一人其实在半山腰就折返了，却仍想领走“登顶勇士”的纪念徽章。你没跟他们一起走，问问一路上发生的事，找出那个没登顶的人。

- 小岳：装备齐全的攻略达人。出发前研究很多路线，说起距离、爬升头头是道。实际上爬到半山就累了，折返后靠攻略描述冒充登顶。
- 阿宁：一路抱怨的普通人。开口就是“再也不爬了”，连登山杖都想转手。但她确实走到山顶，记得沿路的小狼狈。
- 老许：慢悠悠的拍照爱好者。大家以为他落在最后，实际上他一直走自己的节奏，亲历当天路线上的变化。

核心线索是“攻略与当天实际情况不同”。这条路线平常经过木桥，但当天木桥封闭，所有登顶者都从旁边的石阶绕行。小岳自然描述攻略：“过了木桥再往上走，最后那段就到顶了。”阿宁记得：“桥不让走，旁边那段石阶爬得我腿都抬不起来。”老许能说明封闭提示设在半山休息点之后，还在那里等过喘气的阿宁。小岳折返得早，没见到变化。

玩家不靠“装备党肯定不行”“喊累的人才是真高手”猜，而把三个人讲的同一段路对起来，发现谁讲攻略、谁讲当天经历。

小岳：“我精神上已经登顶了。”领队：“那徽章也精神上发给你了。”

原建议三人、四分钟，相比江苏案多一层交叉问话，不需要懂徒步术语、算速度、背海拔或看地图。

## 用户纠正与最终范围

用户明确：“这个故事整体没问题，不过需要注意，一般徒步都不是以登顶为目标的，登山才是；所以可以稍微改一下，让它更接近徒步而不是登山。”

后续改为从村口出发、沿溪穿林地再回村的徒步环线，目标找半程原路折返者；木桥封闭后沿岸绕至下游小桥，保留攻略与当天不同的推理点。用户随后明确批准该版实现、首页第二及PR preview验证；原登顶情节不进入正式JSON。
