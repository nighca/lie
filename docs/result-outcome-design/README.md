## 推荐：结果先由大图形说明，人物再给出自己的反应

保留中文 B 黄底、奶白卡、深蓝描线和既有版式。页面主信号独立于人物 accent、表情和动画可用性。

| | 指认正确 | 指认错误 |
| --- | --- | --- |
| 第一眼图形 | 深蓝大勾＋放射状章 | 深蓝大叉＋圆章 |
| 颜色与纹理 | 浅薄荷色结果头区、垂直节奏条纹 | 浅珊瑚色结果头区、明显斜纹 |
| 人物周围构图 | 圆润开放形、少量星光 | 稍偏斜的矩形与折角描线，保留居中紧凑布局 |
| 人物视角 | 被看穿后的无奈、轻轻泄气 | 错愕后不解、克制地表示不认同 |
| 动作建议 | 约 1 秒，眉眼收敛、视线稍下移、肩轻落，然后停住 | 约 1 秒，眉稍抬、头微后倾／转正、一手轻摊，然后停住 |
| 文本与操作 | 原“指认正确／谜题解开了”、完整经过、原三项操作 | 原“本局结束／指认不正确”、终局短说明、原三项操作 |

玩家成功不意味着人物也在庆祝：角色被正确指认时不做胜利手势或开心跳跃。错误时不做指向别人、看向另一个头像、对白或新供词；不透露真正答案，也不暗示能在同局继续尝试。双方都只展示 `result.characterId` 对应的实际被指认者。

角色动作沿各自现有姿态设计，不给所有人套同一摇摆／纵向拉伸。头与接触手保持刚性关系，脸型不缩放，肩部与手臂按角色装配局部运动。页面图形只做一次可省略的轻量出现，人物一次结束后保持同一静态终态；长文阅读期间不持续演出、循环抖动或播放声音。

## 静态与窄屏底线

即使去掉颜色、隐藏结果字样、人物缺图，勾／叉、放射章／斜纹框仍各自成立。这是设计者观察与截图，不冒充用户盲测或可用性研究。

- 有新结果静态图但无动画：直接显示对应终态；页面结果标识始终在。
- 减少动态：直接对应终态，省略勾号描画与人物短动作；运行中切换也不等待播完。
- 旧四态角色／仅静态角色／无结果图：default；再失败回姓名首字，不切换成另一人。
- 窄屏：图形章仍有 72px，人物舞台 220×180，单列正文与操作，无固定底栏或正文内滚动框。颜色不由人物衣服决定，避免角色与结果混淆。
- 正确页保留所有经过、分段和长姓名；错误页保持终局短说明。焦点和返回／重开／改编语义沿当前已批准实现，新增视觉不改玩法。
