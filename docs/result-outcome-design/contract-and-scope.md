# 人物结果表现接口与制作范围（提案，未改正式契约）

## 输入沿现有结果事实

既有 `GameView.result: { characterId; correct } | null` 已实现，不新增规则、答案投影或指认次数。页面由 `correct` 派生人物视角的逻辑状态；以下名字只是提议，尚非正式 JSON schema：

```ts
type ResultReaction = 'accusedCorrectly' | 'accusedWrongly'
```

`characterId` 用于解析当前案件人物与 `appearanceId`，后者引用预置；不把预置 ID 当案件人物 ID，不取最后询问者或真正答案。任何人数／官方案／分享案／编辑器试玩使用同一映射。

## 推荐的资源边界

1. appearance／CharacterPreset 继续引用独立形象动画包，结果动作也放在同一包内，复用头、身体、眉眼、嘴和手型；不按动画复制一份角色或引入另一播放器。
2. 预置增加**可选**的两张结果静态图引用，服务减少动态、无动画和加载失败；具体字段名／固定路径由后续契约提案确定。它不是必填六套素材，旧四态包和旧静态形象继续可用。
3. 动画包保留现有四个必需基础态，结果映射可选；动作 `loop:false`，沿现有末帧保持能力，不新增视频或第三方引擎。如何标注扩展版本、严格校验可选状态、旧运行时拒新字段及版本化资源发布，须同批技术审查；不能把草图直接塞进现行严格 v1 四态 parser。
4. 对应结果静态图与短动作末帧必须在构图、头型、手势、衣物和遮挡顺序上相同。新图片尺寸沿各自预置的既有画布，不统一硬写 1254 或复制调查页 130% 取景；结果舞台单独 contain。
5. 新数据仍走现有源清单／生成器／hash 资源发布链；不在应用手写正式图片 URL。包内只定义一次结果状态映射，不在清单重复存 clip 名表。

## 读取策略

| 条件 | 人物显示 | 页面结果信号 |
| --- | --- | --- |
| 具备两态动画和静态，允许动态 | 对应短动作一次，末帧保持 | 相应大勾／大叉及纹理 |
| 减少动态、仅静态或动画失败 | 对应结果静态图 | 同上，静止 |
| 旧包没有该结果态 | 对应结果静态图；没有则 default | 同上，不依赖角色资源 |
| 预置不存在／default 也加载失败 | 实际姓名＋姓名首字 | 同上，保留整个结果框 |

进入结果只触发一次；重渲染、回前台和 reduce 开关不反复重播；重开一局后新结果可再触发。结果阶段已有停止语音与旧事件隔离，表现层不重启麦克风、不生成台词或声音。新非循环状态需要解析／迟到加载／卸载／中断／隐藏恢复／末帧／缺态测试，但本稿不宣称这些扩展已实现。

## 动作制作流程（批准后的建议）

- 先选珊瑚短发：保存既有四态和素材 hash；设计“被看穿／被错指”的两套眉眼、嘴与手肩终态，确认原图风格和头颈装配。
- 先完成两个静态终态，再在共享部件上做约 0.8–1.0 秒短动作；禁止用头部缩放代替情绪，避免连续纵向拉伸。
- 自验：首末帧、整个动作与中断、头手接触、衣袖／领口、发顶及完整姿态安全边距；正常游戏尺度及局部原生检查。静态／动画末帧一致，reduce 和失败回退有真实图。
- 样片审查通过后，剩余七人分两条独立制作 lane；每人根据现有动作语汇设计，不批量套同一幅度。发起者负责审查与合入，原已批准四态不重复索要整体视觉批准。
- 候选先留独立制作目录；包、工具链与 UI 各自审查后，统一走常规本地候选／组合验证／串行 main 集成，无 PR 路径。

## 工作量与所有权估计

这是范围估算，不承诺具体墙钟时间或生成次数；新脸／手部素材质量和原装配可复用率是主要变量。

| 工作包 | 可交付规模 | 主要依赖 |
| --- | --- | --- |
| 页面结果信号 | 一组正确／错误 UI，共享标识、两种纹理，桌面／391／回退 | 本轮视觉批准；App/style 文件所有权由主协调安排 |
| 可选资源契约与读取 | 动画契约／组件、预置清单／生成器、结果 UI 解析三处边界及相应测试 | 具体字段与版本技术审查；无须改规则／语音 |
| 首位角色样片 | 2 个终态＋2 个短片＋回退图及制作记录 | 视觉方向、契约；先以此校准后续人均工作量 |
| 全八人 | 共 16 个终态＋16 个一次短片（含首位），共享部件按实际复用 | 两条生产 lane；逐人自验和发起者审查 |
| 组合接入 | 正误真实人物投影、旧角色与新角色混用、长文、reduce、失败／换局生命周期 | 角色与契约到位；相关自动化＋实际应用检查 |

备选 S 少去 16 段短片和动画状态接入，保留 16 个终态、静态读取和同一页面信号。本稿未授权任一工作包进入生产。
