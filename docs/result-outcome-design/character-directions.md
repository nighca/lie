# 八种造型的反应侧重点（方向草案，未制作）

这些是造型／装配约束，不给 appearance 写死案件姓名、性格或道德判断；同一造型可在不同官方／分享案件中扮演不同人物。所有角色仍以“正确＝被看穿后的无奈、错误＝被错指后的不解”为共同语义，具体幅度在首样片和原生装配检查后决定，不能把下表直接作为已批准参数。

| 造型 | 被正确指认 | 被错误指认 | 复用／关注点 |
| --- | --- | --- | --- |
| 珊瑚短发 | 原先自然表情收敛，眼神略低、肩轻落 | 眉稍抬，头微后倾后转正，克制不解 | 首样片；头颈连接沿既有装配，不用头部缩放 |
| 阳光小胡子 | 笑意收住、轻轻抿嘴，肩放松 | 眉抬后小幅摊手，不做夸张摇头 | 胡须随脸刚性运动，口部不穿越胡须边缘 |
| 蓝衣眼镜 | 视线略下移，停在有点无奈的中性嘴形 | 轻抬眉与单手小幅回应 | 眼镜随头，不漂移；保留已修好的袖口／手部层级 |
| 银发盘发 | 眉眼稍收、肩轻降，动作更慢 | 头小幅转正，眉抬、掌轻开可选 | 保留头手接触关系及单纽扣／衣料重叠；不重新引入整人摇晃 |
| 灰白胡须 | 嘴角放平、目光稍低，停住 | 稍抬眉、克制不认同 | 胡须和嘴型轮廓同源；手臂贴合袖口 |
| 紫衣短卷发 | 小幅低头，身体站稳、减少动作 | 轻偏头后停在疑问姿态 | 延续清晰领口和腕部遮挡，不让全上身一起旋转 |
| 薄荷双丸子 | 眉眼柔和收敛，肩轻放松 | 一次轻偏头／轻摊手，不反复摆动 | 发团不碰边；头与接触手整体刚性，衣身独立 |
| 赭黄雀斑 | 笑意收敛，微低头，手势停稳 | 眉稍抬、掌略打开，疑惑但不责备 | 始终同一头型／尺寸，不用整头纹理切换来模拟嘴形 |

所有动作一次后停，减少动态直接显示同一终态；不出对白／新供词，也不通过视线、手势或额外头像提示真正答案。若新手型／眉眼素材不足，先报告补件范围，不用不协调的整块拉伸顶替。
