## 最小方案与未来两态

| 方案 | 视觉效果 | 前置与边界 |
| --- | --- | --- |
| A，推荐先落地 | 现有 default 静态立绘，文字说明正误；本原型完整展示 | 不需新资源或动画契约；不声称已实现两种情绪。也可沿用现有 idle，但本设计更推荐静态以利长文阅读 |
| B，推荐后续批准 | 每个角色可选两种结果静态姿态，表达正确的懊恼/无奈、错误的不解/抗议 | 需视觉批准、逐人资产生产与可选静态资源契约；旧包继续 default；不能给所有现有包强制六态 |
| C，B 之上的可选增强 | 约 1 秒短动作，一次后保持 B 的同姿态末帧 | 需另批可选结果动画与生命周期接入；沿既有 non-loop 能力，不另造播放器。不推荐持续表演循环或再次开麦/配音 |

正确反应采用人物视角的“被看穿后的轻轻泄气”：眉峰小幅内收、视线稍下移、肩轻降，停在无奈姿态。错误反应为“错愕后克制地否认”：眉抬、头轻后倾，必要时一只手轻摊，保持疑惑/不认同。不将玩家胜负喜悲直接贴到人物身上；不做夸张崩溃、羞辱、威吓或暗示真凶。不用现有 listening/speaking 静态图冒充结果表情。

反应方向页的 0–200 / 200–650 / 650–1000ms 是可讨论的节奏说明，不是已定参数；本批没有改变人物脸、骨骼、动作、PNG、动画包或正式 manifest。

## 可访问性、回退与接入边界

- 明确结果标题 h1、内容 h2、姓名文本和两个原生操作。正误不只靠颜色辨认。人物图为装饰性（姓名已可读），不使用 canvas 代替文本。实施时进入结果页将焦点移至 h1（`tabindex=-1`），下一 Tab 按原顺序到操作；静态原型不会模拟应用路由焦点。
- 对本地缺图入口，保留相同舞台和可读姓名，图隐藏后显示姓名首字。正式版查预置缺失/图失败同样回退；动画失败回对应已存在结果静态，否则 default，再失败回首字。不能因为缺资源展示另一人。
- A 完全静止，无定时器/RAF，系统 reduce 开关前后外观相同。未来 B/C 在 reduce 时直接呈现对应静态姿态，不先播放再停止；没有对应图时 default。运行时切换 reduce、隐藏/恢复、卸载、迟到加载由既有组件边界负责，但需实施阶段验证；本原型未验证这些播放器行为。
- 结果舞台单独定尺寸和 contain 取景，不能直接套调查页 130% 绝对定位 canvas 造成裁切。未来 canvas 与静态图必须共用相同构图，结果场景应隔离样式，不改调查/Editor舞台。
- 保留 restart、返回含自编案件时的既有 returnLabel/路由行为。原型固定“返回案件列表”只展示官方案样式，不另定共享案的返回策略。
