# LIE 首版玩法提案

状态：供评审的设计草案。已确认桌面浏览器 Web、三名嫌疑人、现代单人自由语音审讯；大模型与语音使用灵矽。以下交互与规则为建议，尚未获得用户确认。以 2–3 天完成一局可玩 MVP 为目标。

## 一局怎么玩

| 阶段 | 玩家操作与系统反馈 |
| --- | --- |
| 接案 | 阅读简短案情，可播放介绍；看到调查目标、三名嫌疑人和初始证据。用一句话说明“问话 → 对照证据 → 出示质疑 → 提交结论”。点击开始调查。 |
| 审讯 | 点击人物卡进入该角色对话，自由语音提问；界面显示识别文本、角色回答和收音／等待／播放状态。建议保留文字输入作为错听与设备异常时的补充。 |
| 切换角色 | 随时点击另一个人物，查看并继续该人物的对话；各人物保留本局证词和已出示证据。切换前结束当前发言并停止播放，避免串话。 |
| 查看与验证 | 打开证据卡阅读来源与内容；从固定调查入口取得补充材料。玩家自己比较材料与证词，系统不自动标出“此人在撒谎”。 |
| 出示证据 | 在证据详情点击“向当前人物出示”，再自由说明质疑。已出示状态明确可见；角色围绕这份真实材料回应。 |
| 结案 | 随时打开结案表，选择责任人、关键证据及其支持的结论，补充一段推理说明；确认提交。 |
| 反馈与重开 | 成立时展示证据如何构成证明；不成立时给出缺失的证明方向，可继续调查。主动放弃可揭晓完整真相并结束本局。结束后可以重新开始，清空本局进度。 |

**待确认：** 采用“语音自由问话 + 按钮切人、出证、结案”的混合交互。按钮让玩家清楚知道证据是否真的送达、当前在问谁、何时正式提交；自然语言负责追问与表达推理。首版不要求口头指令完成所有操作。

## 证据从哪里来

**待确认：** 首版采用固定案卷与有限核查请求，案件内没有场景漫游或物品搜索。

- 开局提供两份基础材料，足以形成第一轮问题。
- 案卷另有三个预先写好的核查请求，例如调取某段记录、核实一项时间信息、复核一份材料；具体内容随案件确定。
- 请求从开局即可点击，每项领取一份固定结果，不设等待倒计时、隐藏关键词或提问次数门槛。未领取状态与领取结果清楚区分。
- 对话中可以获得可供核查的说法，但玩家不必逐字问出指定句子才能继续。嫌疑人的说法不自动变成客观事实。

这样全局约五份客观材料，足以支持三人之间的交叉询问，也能让第一次游玩的玩家找到调查方向。若某项核查必须依赖前置材料，应在案卷直接说明依赖，不隐藏触发条件。

## 主界面文字草图

```text
[案件名 / 调查目标]                          [操作说明] [提交结案]

[人物 A] [人物 B] [人物 C]       | 案卷
当前人物：姓名、身份              | 初始材料 / 补充材料
                                | 核查请求（3 项）
本人物的对话记录                  | 点击一项查看：
玩家问题 / 人物回答               |   来源、正文、获取状态
                                |   [向当前人物出示]
已出示：材料名称                  |
[收音 / 等待 / 播放状态]         | [需要提示]
[开始/结束说话] [文字输入]        |
```

证据详情优先保留当前对话上下文，关掉后继续追问。结案表单展示人物选择、证据与证明关系、推理说明；提交前明确提示这是正式判断。结算页解释“哪些推理成立、哪里仍有缺口”，结束后可展开完整真相。

## 怎样认可推理与证词变化

- 案件规格预先定义少量关键事实、允许隐瞒的说法、矛盾及突破条件。角色遇到压力可以回避；满足条件后可以承认或纠正，但不能自行改写时间线。
- 出示按钮记录确定的证据编号；玩家口头声称“我有监控”不会获得或出示监控。语义理解允许同义改写、不同问序和自然追问，不以命中特定词句推进。
- 有效质疑结合“真实材料已出示 + 玩家质疑的事实关系 + 当前角色允许承认的内容”判断。语义识别结果若用于推进，必须与案件允许的状态变化匹配。
- 重要改口在记录中保留原说法与新说法，并标记“已更正”；更正不会覆盖历史，也不等于自动证明此人作案。
- 首版结案要求责任人正确，并提交案件预设的关键证明组合，包括支持归责的证据关系和排除主要替代解释的依据。表单允许选择有限的证明关系，避免胜负完全依赖对自由文本的主观评分；解释文字作为补充。
- 猜中责任人但依据不足，反馈为“结论尚未证实”；错误指认也可继续调查。仅靠逼角色说“是我做的”不能替代证据。

**待确认：** 结案采用以上结构化证明方式；具体证明关系在案件确定后编写和评审。

## 提示、时长与首版取舍

**建议：** 一个按需提示按钮，按“建议调查方向 → 建议对照的材料 → 更具体的矛盾”逐级展示预写提示，使用前说明提示会逐步具体。提示不代替结案，也不要求实时生成。

**待确认：** 首版不设倒计时、次数限制和复杂分数；结算用“结论与依据是否成立”及解释反馈，保留用时和提示次数作为参考。三名嫌疑人下 3–6 分钟仅是待试玩验证的预期，不能据此强迫缩短关键推理或提前结束游戏。

验收重点：未读过剧本的玩家能理解操作、走通三人问话与证据核查、以合理依据结案；换个问法与调查顺序仍能完成；继续调查与重开都不丢失或串入不应出现的状态。
