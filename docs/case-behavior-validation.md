## 脚本与安全边界

`resources.ts` 独立创建1个generic无记忆智能体、3个临时设备，提示逐字复用 `apps/gateway/scripts/linx-check.ts` 当前通用系统提示。不读/改8787、5188状态。`probe.mjs` 使用实际 core `buildCharacterContext`（TypeScript原源码转译至被忽略tmp），同应用的角色工具返回JSON与显式history；不人工重写profile或上传其他人的资料/ending。每轮MCP读当前上下文，文本 `listen.detect`，不采麦克风。

上限9连接/9回答、每连接45秒、10秒握手。协议失败立即停止剩余轮次，不盲重试。正常输出只记阶段/计数，固定游戏问答记录于本地忽略的results.json，人工审阅后再写结论。raw音频只计帧/字节，不保存。需要tools/call、一个TTS回答、stop、PCM；这些只是协议检查，不是语义断言。失败仅记安全原因和角色/问题，不打印header/key/token。

状态0600且tmp被忽略；管理API仅打印操作、HTTP与业务码。无论通过/失败都由执行者立即运行cleanup，解绑自己的3设备并删除自己的智能体；若TLS等失败，保留状态，只重试cleanup。不得重新setup/推理。资源创建过程中若远端成功但响应丢失，记录未确认，不猜ID或清理其他资源。
