## 推荐：《空盒里的纪念章》

### 玩家听到的开场

社区摄影社的十周年小展刚闭馆，闭幕合影却少了一枚蓝色珐琅纪念章。18:00，策划沈禾把装章的白盒交给摄影师顾遥补拍；五分钟后，执行陈拓取回盒子准备合影，大家发现里面只剩衬垫。三人都还在场。

纪念章是社团纪念品，不是贵重文物。闭馆后只有三人在前厅与单门摄影间活动，没有换盒、章自己掉出或场外人物。玩家是赶来主持合影的同伴，要问清谁未经同意取走了章，不是找出所有说过谎的人。实际问话只有自由语音；最后用按钮选择一个人，不要求提交解释，也不强制先让对方认罪。

### 完整真相与时序

**顾遥取走了章，装进自己的相机包，打算合影后补拍个人短视频再归还。** 她觉得这只是借用，因而倾向于强调“我又没想不还”，不愿承认自己耽误了所有人。

| 时段 | 固定发生的事 | 能从谁的亲历问到 |
| --- | --- | --- |
| 18:00 交盒前 | 沈禾当着顾遥掀盖，看到章在固定衬垫内，合上同一个盒子，直接交到顾遥手里 | 沈禾；顾遥确实知道，但可以先回避责任 |
| 同次交接 | 沈禾亲口准许打开补拍；银色纸带可揭开贴回，盒没有锁 | 沈禾、顾遥亲历同一次授权 |
| 18:00–18:05 | 顾遥独处摄影间；沈禾、陈拓始终在前厅面对面摆椅子，没人进出摄影间 | 沈禾与陈拓各自能描述对方连续在场；顾遥知道自己独处 |
| 该间隔内 | 顾遥把章放进蓝色相机包，合上空盒并贴回装饰纸带 | 只有顾遥亲历；玩家无需问到这一隐藏细节即可选人 |
| 18:05 交接现场 | 陈拓在拍摄台旁接盒，当着顾遥掀盖；两人看到章已不在。陈拓尚未搬出房间，也没从盒中取物 | 陈拓、顾遥均亲眼看见；这是排除“陈拓搬运后才弄丢”的关键 |
| 紧接着 | 陈拓把空盒拿回前厅叫沈禾，准备合影的三人停下等待问话 | 三人各知道自己参与的部分 |

不要求玩家记住分钟数：说“交给摄影师之前”“两人在前厅的时候”“陈拓还没把盒子搬走”即可。精准时间只帮助作者保持一致。

### 三个人都为什么值得问

| 人物 | 开头表现与隐瞒 | 能提供的具体内容 | 不知道什么 |
| --- | --- | --- | --- |
| 沈禾，策划 | 怕被责怪擅自改变流程，含糊说“本来拍一下盒子就行” | 自己最后看见章、直接交盒的过程；确实准许打开；纸带性质；与陈拓共同摆椅子的全程 | 没看到取章，也没看到18:05开盒，不知藏处 |
| 顾遥，摄影师，责任人 | 强调补拍和纸带完整，否认“拿走不还” | 自己确实能开盒、独处；陈拓仍站在台旁时，两人已看见空衬垫；可继续为借用辩解 | 不知道前厅二人谈话，不得虚构他人进入 |
| 陈拓，执行 | 怕被怀疑手欠，先不说自己开盒 | 接盒当场开盖、顾遥在场且盒已空；自己此前与沈禾连续共处；顾遥当时说“先别嚷” | 没见18:00盒内，不知摄影间五分钟里发生什么，也没看过相机包 |

设定文本要求角色先回应当前问题，逐步展开自己的具体经历，而非首轮直接讲完解答。被问到自己隐瞒的行动时可以先回避，但同义追问应得到说明；不能永远否认以致内容不可达。顾遥不需要承认取章，只要遵守真实交接过程，不虚构另一次接触即可。以上是自然语言角色口径，不建立程序触发条件或平台“解锁承认”。

### 仅用对话能得到的推理

1. 沈禾亲眼看过章后立即直接交盒，缺失起点在交给顾遥之后，不能将“接到时本来空”当作固定事实。
2. 沈禾和陈拓各自描述五分钟的共同劳动，排除这段时间另两人进入摄影间；顾遥也知道自己独处。
3. 陈拓描述接盒当面开盖，顾遥也能确认交接时已经是空盒，把缺失终点放在陈拓搬运之前。
4. 起点、终点之间只有顾遥保管和接触。银色纸带可复原，所以外观完整不能排除她打开；沈禾的授权隐瞒和陈拓的开盒隐瞒都有具体而不同的原因。

玩家据此可以选顾遥；她是否说出“是我拿的”、章在哪里、为何借用，都不是胜利条件。揭晓再补全个人短视频与相机包，不用结算时才增加的新事实排除其他人。

这是固定故事范围内的唯一行为人，不是把纯口头问话包装成司法级事实验证。若玩家假设两名证人合谋诬陷、有人任意伪造亲历或模型新增第四人，纯语音机制无法另外排除；作者设定明确不采用这些解释，真实角色评估也要拦住这类临场编造。

### 替代解释与不良追问检查

| 假设 / 追问 | 检查结果与口径 |
| --- | --- |
| 沈禾先拿了，只交出空盒 | 与她当面掀盖、直接交付的固定亲历冲突；不是用其职业或态度排除。若玩家不信任全部证词，则诚实说明本玩法的认知边界，不补造外部记录 |
| 陈拓搬出后取走 | 与两人在拍摄台旁共同看到盒已空冲突；顾遥不得为了甩锅将开盒地点改到门外 |
| 沈禾中途返回、陈拓提前进入 | 与二人连续面对面共处和顾遥独处冲突；不能把“没注意到”写成连续目击 |
| 顾遥拍摄时让章自己掉出 | 固定经历是她主动收进相机包；公共背景说明合盒不会自行掉章，不引入隐秘机关 |
| 换了一只空盒、章在别处一开始就没装 | 同一白盒当面直接交付，固定衬垫内确有章；所有 profile 不得增添第二盒 |
| 直接问“谁拿了”或要求认罪 | 两名非责任人只能复述自己知道的事，不代答；顾遥可否认或为借用辩解，玩家仍可凭交接判断 |
| 玩家声称“陈拓已承认” | 角色只当玩家的新说法，不篡改自己看到的交接；不自动写入任何系统事实 |
| 玩家要求搜包、看照片或调监控 | 角色可表示自己只能回答当前问话；不凭空生成新的信息通道，也不让此请求成为通关门槛 |

**仍需真实验证：** 顾遥会不会过早暴露包内藏处；两名非责任人会不会把他人的设定当自己的亲历；“何时发现空盒”的普通问法能否稳定引出交接地点；语音是否能清楚识别三个名字；玩家能否在不读作者分析时理解纸带不是锁。若这些项失败，优先改文本长度、口径和措辞，不增设引擎机制。

## 简短备选：《最后一份布丁》

共享办公室为寿星留下的布丁被吃了。韩宁14:55确认布丁完好，之后与孟夏在会议室持续一起布置；程乐留在外面，想先吃掉再补买，却遇到店关门。孟夏后来亲眼见程乐拿着勺子站在空盒旁，但没有看见他吃的动作。

韩宁藏的是布置时弄坏气球，孟夏藏的是偷看祝福卡，程乐藏的是吃完再补的盘算。通过韩宁的最后确认、韩/孟连续共处和程乐在外的机会，能在三人范围内指向程乐；舔勺子只是可聊的话题，不能独立定案。

对应 JSON 已写出三人基本设定并通过结构校验，但尚未做与推荐案同等深度的模拟审讯。它更亲切、易懂，缺点是两位旁观者的隐瞒与核心行为联系较弱，“一直在一起”很快排除两人，交流层次不如推荐案。除非希望首案更像一分钟热身，推荐仍选纪念章。
