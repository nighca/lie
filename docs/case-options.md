# LIE 首案候选

状态：供评审，两个案件均未定案，最终由用户选择后再细化为正式案件规格。

共同前提：现代背景、单人、桌面浏览器 Web、3 名嫌疑人、自由语音审讯，使用灵矽提供模型与语音服务。以下案件为本项目原创设计。首轮目标是验证推理与审讯，3–6 分钟时长仍待试玩验证。

本文包含全部真相，会剧透。表格中的事实是待实现的剧本约束，不是已经接入或实际存在的外部数据。角色只能改变表达和隐瞒程度，不能新增人物、通道、设备、证据或作案方式。

## 候选 A：《最后一次发布》

### 开局与真相

一家创业公司准备在 20:00 向媒体发送产品演示包。发送前十分钟，合作方收到了一份含有核心算法源码的文件。发送记录指向技术负责人，产品经理声称自己当时一直在会议室，行政助理则坚称没有人离开会场。

**真相：产品经理林岚在 19:48–19:50 使用公共演示电脑中未退出的技术负责人账号，将原定演示邮件的附件替换为源码包，并提前发送。** 她与一家竞争公司约定以泄密换取职位；她随后回到会议室。技术负责人隐瞒自己违规把源码包放上演示电脑的行为，行政助理隐瞒自己擅自中断签到值守、去帮林岚打印离职材料的行为。

案件调查的是“谁主动向外发送了源码”，不能仅凭准备源码或离职意图认定泄密。

### 三名嫌疑人

| --- | --- | --- | --- |

| 林岚，产品经理，真凶 | “19:45 到 19:55 我一直坐在会议室。提前发信可能是周衡设置的任务。” | 19:48 借口取电源离开会议室，替换附件并手动发送；竞争公司承诺接收她。 | 唯一知道接收方为何提前索取源码、自己如何操作的人；初始可以谎称自动发送，不能编造真实存在的定时任务。 |

三人的作用分别是解释“账号为何不能证明人”“谁实际具有操作机会”“为什么目击者先说谎”。许宁不是额外的陪衬嫌疑人：她也曾独自离岗，初始具有机会，必须通过证据与证词核对排除。

### 排除与结案要求

已知现场仅三人能接触演示电脑；该客户端当时无远程控制，邮件记录已区分现场手动操作与其他发送方式。房间无另一个出口，不能通过打印室进入。以上边界应在案卷“现场勘查”中明确给玩家，不能在揭晓时补充。

1. A1、A2 确认有人在演示室主动替换附件并手动发送。
2. A3 解释账号归属造成的误导；A4 排除周衡亲自操作，亦排除他预设了该次发送。
3. A5 排除许宁在发信窗口进入演示室。
4. A4、A6 将唯一剩余的林岚锁定到现场。她所谓“始终在会议室”“自动发送”均被独立记录推翻。

最低成立结论：指认林岚，说明“现场手动替换与发送”“账号冒用的条件”“另外两人的时间证据”。竞争公司收买是揭晓可补充的动机；离职材料只提示动机，不应让玩家凭此证明收买。

### 两条合理调查路径

- **从技术记录入手：** 追问周衡发信账号 → 出示 A3 迫使承认源码与未退出登录 → 用 A1、A2 确认具体操作 → 用 A4、A5 排除二人 → 向许宁核实 A6，质问林岚。
- **从人物谎言入手：** 追问许宁签到细节 → 用 A5 揭穿离岗并解释离职材料 → 获得 A6 目击 → 用 A4 追问林岚离席 → 向周衡核实 A2、A3，再用 A1 推翻自动发送辩解。

### 未知与漏洞审查

- **术语门槛：** 摘要、客户端、源码包需要用人话解释；若试玩者花大量时间理解技术背景，应选候选 B。
- **记录过强：** 证据齐全时机械排除较快。对话应承担解释记录含义、揭露秘密和反驳说法的作用；不可为了延长时间随意藏证据。
- **前提必须公开：** 无远程控制、三人范围、单一出入口是推理必要前提，未公开则不能唯一指认。
- **证词可信度：** 不能只靠许宁指控定案，A6 必须保留门记录与 A4 的交叉验证；还须通过语音试玩检查玩家是否误把刷卡等同于本人。
- **动机不可过度评分：** 收买尚无独立物证，首版不能要求玩家证明具体交易金额、接收人身份或“换工作”约定。

## 候选 B：《空盒里的纪念章》

### 开局与真相

社区公益拍卖即将开始，一枚捐赠的金质纪念章在彩排后失踪。展柜没有被撬，装章的黑盒看上去仍然封好。负责保管的策展人、拍摄宣传照的摄影师、运送物品的活动执行各说自己没有打开过盒子。

**真相：摄影师顾遥在 18:10–18:13 拍照时取走纪念章，塞入随身镜头包，重新合上盒子并贴回磁吸搭扣上的装饰封条。** 她欠债，准备散场后私卖。策展人隐瞒擅自允许拍摄时开盒的行为；执行隐瞒彩排中摔过盒子、偷偷更换外部礼袋的行为。纪念章失踪不涉及真假调包或复杂机关。

### 三名嫌疑人

| 人物 | 初始说法 | 实际行动与秘密 | 不可替代的信息与知识边界 |
| --- | --- | --- | --- |
| 沈禾，策展人 | “我装好之后，任何人都无权开盒。” | 私下让顾遥开盒拍照，又担心违反捐赠人要求受罚而否认。18:08 交接前亲眼检查纪念章仍在。 | 唯一知道封条是可重复粘贴的装饰材料、现场只有一枚章且没有替代品的人；保留交接称重原单。她不知道摄影期间发生什么。 |
| 顾遥，摄影师，真凶 | “我只拍了封好的盒子。拿到时就很轻，章可能早就不在。” | 拍摄期间取章；为解释照片，谎称开盒照片拍于较早时间；欠债。 | 唯一知道相机照片的拍摄顺序和镜头包藏匿点的人。可以否认、辩解，不能增加第二台相机、外借照片或拍摄者。 |
| 陈拓，活动执行 | “我收到什么就原样送进展柜，途中没有停留。” | 18:15 搬运时摔了礼袋，换掉破袋并检查盒子外观；怕被追责，隐瞒。 | 唯一知道运输事故与礼袋更换、亲自发现盒子异常偏轻的人；他的交接称重把失踪窗口锁定在摄影阶段。没看过盒内，不知道章在哪里。 |

三人分别解释“封条为何不能当完好证据”“失踪发生在哪个交接阶段”“谁在该阶段接触过章”。陈拓提供排除策展人所必需的第二次称重信息，也因搬运隐瞒成为合理嫌疑人。

| B5 搬运与展柜录像 | 黑盒在摔袋、换袋和入柜期间连续可见，无人开盒，之后展柜未再开启。 | 证实陈拓说谎及真实原因，排除运输或展柜阶段丢失；结合 B1，而不是依赖看清小物件。 |
| B6 镜头包检查记录 | 结案指认后由现场工作人员按固定流程检查，纪念章在顾遥镜头包夹层找到，编号与验收一致。 | 验证结论并用于揭晓，不是让玩家先搜包再倒推。玩家不能通过一句“搜她”绕过此前调查。 |

### 排除与结案要求

公开案卷须说明：验收流程可靠，秤在现场校验正常；称重的是同一黑盒与固定衬垫；没有其他物品可取出补足重量差；唯一纪念章全程在场内，没有共犯、暗门或远程机关。B1 的原单必须可查，不能仅由角色口述重量。

1. B1 显示纪念章在 18:08 交给顾遥时仍在、18:13 交给陈拓时已不在，锁定窗口；B2 进一步确认窗口中确实有章。
2. B3 证明窗口内只有顾遥能接触黑盒，排除沈禾回来取走、陈拓提前取走等解释。
3. B4 解除完整封条造成的误导。沈禾说谎是在掩盖违规授权，不能因此认定偷窃。
4. B5 与交接重量共同排除陈拓搬运失误导致失踪；礼袋事故是独立秘密。

最低成立结论：指认顾遥，指出两次交接之间章消失、期间独占接触机会，以及封条可复原。B6 在提交结论后验证；欠债作为揭晓动机，不要求靠外观、职业或态度猜出。

### 两条合理调查路径

- **从重量入手：** 问沈禾验收流程 → 查 B1 第一次重量 → 向陈拓核实第二次重量和异常 → 查 B3 锁定顾遥 → 用 B2 反驳“本来就是空盒”，再由 B4 解释封条。
- **从完整封条入手：** 追问沈禾谁能开盒 → 用 B2、B4 揭穿违规授权 → 质问顾遥照片时间 → 用 B1、B3 确定失踪窗口 → 调查陈拓说谎，通过 B5 排除搬运事故。

### 未知与漏洞审查

- **称重合理性：** 需要用“贵重捐赠品每次交接称重留单”这一简单流程解释，不能让玩家以为临时巧合出现两张单据。陈拓没发现问题的理由是他不知道标准总重，交接时只按流程记录；此点要在人物设定中固定。
- **现场限定必须自然：** 案件应在发现失踪后立即开始，三人均留场，避免“为何凶手还没把章带走”的漏洞。
- **重复粘贴封条：** 开局将其称作装饰封条，不能暗示它是专业防拆封签。盒子本身没有锁，展柜有锁，两者不可混淆。
- **证据取得不应循环：** B1–B5 的原始材料均已由现场保全；追问帮助玩家找到、解释材料，不能要求先指认顾遥才能取得关键称重单。
- **难度偏低：** 相比 A 更易理解，适合作为首轮体验；若全部卡片同时展示，解题可能过快。是否按调查主题展开材料需要产品讨论，不能把猜中关键词作为解锁条件。
- **搜包规则待确认：** B6 当前作为结案验证设计。若产品允许自由要求搜查，必须统一给出“先提交有依据的检查申请”的规则和交互；不能只对真凶临时拒绝搜查。

## 推荐与待确认

**首案更推荐 B《空盒里的纪念章》**：重量变化、交接与封条比技术日志更容易通过语音理解；三个角色各自维护一个不同的秘密，能较快展示“每个人都在撒谎，但只有一人实施本案行为”。它也方便用少量证据卡完成首轮盲测。

A 与已有概念衔接，适合偏技术的 Hackathon 观众，也更能表现账号证据与身份之间的差别。但它需要解释更多前提，现场手动发送、定时任务、远程控制等边界容易占用短局时长。

用户需要确认的是首案题材与期望难度；搜查、证据呈现、动机评分等具体机制可在选案后继续确定。两个候选都应先做人工审讯和逻辑复核，再进入角色提示词与实现。三名嫌疑人不意味着固定三等分对话时长，每人至少应承担一次不可跳过的信息核验。
