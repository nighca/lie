# 两处就地说明 · 交互设计 Demo

2026-11-01。用户在本 Chat 对“建议先在计时区域和指认弹窗就地补清”确认“可以的，按这个来做个设计吧”，并要求“设计结果以可交互 Demo 的形式给我体验感受”。这授权本轮设计体验，不授权正式产品实现、合入、发布或真实语音测试。

## 设计内容

- 剩余时间与两项对话操作保持在同一控制区域。永久短句为“所有人物共享，结束对话后暂停”；具体计时边界由“怎么算时间？”在原地展开，默认收起。
- 展开后解释准备免费、就绪后的停顿/等待/回答均计时、切人共享、耗尽仍能回看指认。另明确说明查看不会暂停，避免帮助本身造成新的规则误解。
- 指认弹窗在人物选项前直接显示“点击人物会立即提交，结束本局；选错不会揭晓答案。”这属于不可撤回操作的事前说明，不藏进可选帮助。
- 保留点人物立即提交与返回调查。没有增加确认按钮、额外弹窗、首次状态、强制引导、开口问题卡或设备帮助。
- 采用既有固定浅色方向：奶油背景/卡片、黄色强调、钴蓝操作和深蓝描边。虚构人物以首字占位，不生成或调整正式美术资产。窄屏把角色选择放在记录上方、计时与规则在操作上方自然换行，不引入另一套玩法。

## 模拟边界

`demo.html` 是独立片段，不导入或修改正式组件。两个虚构人物、两分钟额度、约一秒连接准备、预置两条对话，仅为体验帮助所在的上下文。没有文字输入、实际语音或官方答案；无外部资源、API、账号、Cookie、浏览器 storage 或麦克风访问。

模拟遵循本次相关规则：就绪起扣，停止暂停；活跃切人重准备，停止后切人不自动开；人物各自保留模拟记录；展开说明不停表；打开指认先停止，返回需主动开启；耗尽停止并打开指认，返回后切人不反复重弹。所有指认固定展示明确标注的“模拟结果：指认不正确”，不用于判断人物答案或评价模型。

“重置 Demo”与模拟结果说明只属于设计体验，不是新增正式产品需求。刷新重置所有模拟状态，不保存首次或草稿数据。对话只给一次预置样本，没有自动提问或真实角色行为。
